# 大观园数学桌面版 v1.0.10

修复新版单题模式按空格或点击显示答案时，整个学习区域突然上移、底部露出大片空白的问题。

原因是答案展开后的 `scrollIntoView` 同时滚动题目区及外层隐藏溢出的容器。现在只在题目内容区内定位答案，底部操作栏保持原位；快速显示与隐藏也不会触发过期定位。同步更新页面脚本和离线缓存。

## 验证

- 使用截图对应的真实题库题目（题号 435）、150% 字号复现，修复前外层页面滚动 155 像素，修复后保持原位。
- 回归覆盖空格、操作栏按钮聚焦后按空格、快速显隐，以及字号、自动判题和新旧界面兼容性。
- 使用临时数据目录验证打包后的桌面版，不读取日常学习数据。
- 正式安装器在干净 Windows 用户配置下的安装与升级未实测；沿用未签名发行方式。

## 下载与更新

Windows x64 资产包括 `DaguanMathDesktop-Setup.exe`、`DaguanMathDesktop-1.0.10-full.nupkg`、`RELEASES` 及 SHA-256 校验文件。已安装桌面版可检查更新，下载完成后确认重启安装。
