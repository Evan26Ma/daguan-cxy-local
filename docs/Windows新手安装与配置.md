# Windows 新手安装与配置教程

这份教程写给完全不懂命令行、GitHub 或 Node.js 的用户。你只需要会下载文件和用鼠标双击。

## 先看结论：推荐下载桌面版

[⬇️ 百度网盘下载 Windows 桌面版（推荐）](https://pan.baidu.com/netdisk/share?surl=VrW0Z-ThDSM7f_xx7uCUZw)　提取码：`dgy1`

浏览器安装包已停止维护。已经安装它的用户请按下文迁移到桌面版；两版使用同一份本机学习记录。

桌面版默认打开新版学习区，关闭窗口后仍可从系统托盘恢复；桌面版会在后台检查更新，下载完成后由你决定何时重启。

**请不要下载 `Source code (zip)` 或 `Source code (tar.gz)`。** 这两个文件是给开发者的，普通用户下载后不能直接使用。

## 1. 使用前准备

你需要：

- Windows 10 或 Windows 11 的 64 位 x64 电脑；
- Microsoft Edge 或 Google Chrome 浏览器；
- 至少 2 GB 可用磁盘空间；
- 如果要同步官网进度，准备自己的大观园登录码，或官网账号和密码；
- AI 功能是可选的，没有 API Key 也可以正常刷题和同步。

不需要安装 Git、Node.js、Python 或浏览器扩展。

## 2. 下载程序

1. 点击本页上方的桌面版网盘链接，在打开的页面输入提取码 `dgy1`。
2. 等待 `DaguanMathDesktop-Setup.exe` 下载完成并双击运行。
3. 当前桌面版仍未签名，Windows 可能显示 SmartScreen 警告。公开的 [v1.0.3 安装器](https://github.com/Evan26Ma/daguan-cxy-local/releases/tag/v1.0.3) 文件名为 `DaguanMathDesktop-Setup.exe`，大小为 `425,264,640` 字节，SHA-256 为 `5bd38b60cc08aac401cb337cd9198b7e8d4ae797cc142a997e06e2a99f7cd412`。百度网盘分享里的文件可能仍是旧版，须按实际文件与对应版本的 Release 校验，不能直接套用 v1.0.3 的值。如你不熟悉校验，可请可信任的技术人员帮忙核对，不要关闭 Windows 安全防护。
4. 安装完成后，安装程序会自动在桌面和开始菜单创建“大观园数学”快捷方式；双击桌面图标即可启动，也可以从开始菜单打开。

请不要从聊天群或不明网站下载别人重新打包的版本。

### 从旧浏览器安装包迁移

1. 在旧浏览器页面确认待同步记录已写入服务；若页面提示仍有待同步记录，先下载本机记录备份。
2. 下载并安装上面的桌面版。无需手动删除浏览器服务锁或学习数据。
3. 从开始菜单打开桌面版。它会确认旧浏览器服务身份、等待正在保存的记录写完，再接管同一数据目录与端口。
4. 如发生健康检查或交接失败，按桌面版提示核对进程；不要在服务仍运行时删除 `%LOCALAPPDATA%\DaguanMath\data` 中的实例锁。

最终浏览器迁移包的归档说明见[下载与迁移配置](百度网盘下载与引导页配置.md)。已安装的旧包不会自动收到迁移页面。

## 3. 第一次启动

1. 从开始菜单启动“大观园数学”。
2. 首次启动时本地服务会自动准备题库；学习窗口随后打开。
3. 关闭学习窗口会缩到系统托盘。要完全退出时，从品牌栏或托盘菜单选择“退出大观园”并确认。
4. 桌面版中的新版、旧版学习界面共用 `%LOCALAPPDATA%\DaguanMath\data` 中的进度、收藏、批注和学习位置。

`127.0.0.1` 表示你自己的电脑，不是可疑网站。如果 8080 端口已被其他程序使用，地址可能变成 8081、8082 等，这也是正常的。

桌面版不需要保留命令窗口。日志只写入本机共享数据目录下的 `logs` 文件夹，不会自动上传。

## 4. 不配置账号，也可以先刷题

官网同步和 AI 都不是启动程序的必要条件。想先看看界面时：

1. 在首页选择高等数学、线性代数或概率统计。
2. 继续点击章节，直到进入具体小节和题目。
3. 点击“显示答案”查看解析。
4. 根据情况标记“未开始”、“学习中”、“已掌握”、“易错”或“收藏”。

这些操作会自动保存在本机，不需要手动点击“保存”。

## 5. 首次配置官网同步（可选）

如果希望把大观园官网的掌握状态和收藏带到本地，或者把本地进度同步回官网，请按下面操作。

### 第 1 步：打开配置向导

1. 回到大观园首页。
2. 找到“数据同步中心”。
3. 点击“同步进度”。
4. 第一次使用时，页面会自动进入“配置官网同步”向导。

### 第 2 步：检查本地中控台

页面应该显示本地服务正常。点击“服务正常，下一步”。如果显示服务异常，确认“大观园数学”仍在系统托盘运行，或重新启动桌面版。

### 第 3 步：登录大观园

两种登录方式二选一：

- 有登录码：只填写“登录码”；
- 没有登录码：填写“账号”和“密码”。

点击“保存并登录”。看到“登录成功”后再继续。登录信息只提交给你电脑上正在运行的本地中控台；不要把登录码、密码或 Token 发给其他人。

### 第 4 步：先做只读测试

点击“测试读取”。这一步只读取官网的掌握状态和收藏，不会修改官网数据。看到读取成功后继续。

### 第 5 步：导入官网进度

点击“导入官网进度”。系统会先自动备份，再把官网掌握状态和收藏导入本地。看到“首次同步完成”后，点击“开始刷题”。

## 6. 以后怎样同步

日常使用时：

1. 点击首页“同步进度”。
2. 系统先做只读检查，显示官网和本地各有多少道题需要更新。
3. 看清页面上的同步方向和题目数量。
4. 确认没问题后，点击“确认同步”。

同步前会自动备份。掌握状态、收藏和最近学习位置可参与同步；易错标记、题目批注、AI Key、AI 服务配置和聊天历史永远不会上传到官网。

## 7. 配置 AI 解题（可选）

不配置 AI 不影响刷题。要使用 AI，你需要先从自己选择的 AI 服务商获得以下三项：

- API 根地址，例如 `https://api.example.com/v1`；
- API Key；
- 模型名称。

API Key 不是大观园密码，也不是 AI 网站的普通登录密码。不要把密码填进 API Key 输入框。

1. 打开左侧“工具区”。
2. 点击“界面设置”。
3. 向下找到“AI 服务档案”，点击“添加服务”。
4. “名称”可以随便写一个方便识别的名字。
5. 填写服务商提供的“API 根地址”和“API Key”。
6. 填写服务商提供的模型名，然后点击“保存服务”。第一次保存前必须先填一个模型名。
7. 在已保存的服务卡片上点击“编辑”。如果想确认可用模型，点击“获取模型列表”；如果接口不返回列表，保留手动填写的模型名即可。
8. 点击“测试连接与文本”。只有需要让 AI 看题目图片时，才需要点击“测试视觉能力”。
9. 测试通过后点击“取消”关闭编辑表单；如果修改了模型名，则再点击“保存服务”。
10. 进入一道题，点击题目操作栏里的“AI 解答”，输入问题后点击“发送”。

API Key 只保存在本机。截图求助时，请先遮住 API Key、大观园登录码、账号和密码。

## 8. 以后怎样打开和关闭

打开：从开始菜单启动“大观园数学”。

关闭：关闭学习窗口会将桌面版缩到系统托盘；要完全退出，从品牌栏或托盘菜单选择“退出大观园”并确认。确认退出会断开其他连接本地服务的窗口。

桌面版会管理本地学习服务。你在浏览器中打开本地学习页面时，它也会连接到同一服务；完全退出桌面版前，程序会提醒其他连接窗口即将断开。

## 9. 数据保存在哪里

学习记录、登录配置和本机日志默认保存在：

```text
%LOCALAPPDATA%\DaguanMath\data
```

完全不懂路径时，可以按键盘上的 `Win + R`，粘贴 `%LOCALAPPDATA%\DaguanMath\data`，再按回车。

请不要随意删除这个 `data` 文件夹。删除前先在同步中心的“高级选项”中导出本地数据。

## 10. 怎样更新

桌面版会定期检查 GitHub Release 更新。发现更新后会在后台下载，并显示“重启并安装更新”；只有你确认后，程序才会重启安装。更新不会删除 `%LOCALAPPDATA%\DaguanMath\data` 里的学习记录。

## 11. 遇到问题怎么办

### 安装器双击后什么都没发生

- 检查文件是否已经完全下载，大小应在 400 MB 左右；
- 检查浏览器或 Windows 安全中心是否拦截了文件；
- 不要直接在 ZIP 压缩包里运行；
- 不要关闭杀毒软件或 Windows Defender，只需核对 GitHub 来源和 SHA256。

### 安装时提示 Failed to extract installer（安装包解压失败）

常见原因是安装包下载不完整，或被杀毒软件拦截、隔离。按下面顺序排查：

1. 先核对安装包的 SHA-256 是否与所用版本 Release 公布的值一致（校验方法见上文第 2 步）。不一致说明文件不完整或被改包，重新下载即可，这不是误报。
2. 校验一致仍失败时，查看杀毒软件的拦截记录：火绒在主界面菜单或托盘右键菜单的「安全日志」；Windows 安全中心在「病毒和威胁防护」→「保护历史记录」。
3. 把包含检测名称的拦截记录截图发给维护者求助；如确认被误报，可按[代码签名政策中的误报提交说明](CODE_SIGNING_POLICY.md#向杀毒软件厂商提交误报)向厂商提交。
4. 不要为了安装而关闭杀毒软件。确认校验值一致后，临时把安装器加入杀毒软件的信任区即可。

### 学习窗口打不开或显示“无法访问”

先从系统托盘菜单尝试“显示大观园”。如果本地服务状态异常，完全退出桌面版后重新启动；端口可能变化，不要强行改回 8080。

### 登录失败

先确认登录码是否过期，或官网账号和密码是否正确。回到同步中心，点击“重新运行配置向导”再试一次。登录失败不会删除已有的本地刷题进度。

### 向开发者求助时

请发送学习页面的报错截图、Windows 版本和下载的文件名。也可附上 `%LOCALAPPDATA%\DaguanMath\data\logs` 中相关本机日志；分享前检查并遮住账号、密码、登录码、Token 和 API Key。

截图前一定遮住账号、密码、登录码、Token 和 API Key。
