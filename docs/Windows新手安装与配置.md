# Windows 新手安装与配置教程

这份教程写给完全不懂命令行、GitHub 或 Node.js 的用户。你只需要会下载文件和用鼠标双击。

## 先看结论：你只需要这个 EXE

[⬇️ 点击下载 DaguanMath-windows-x64.exe](https://github.com/Evan26Ma/daguan-cxy-local/releases/latest/download/DaguanMath-windows-x64.exe)

下载完成后双击它，等待浏览器自动打开就行。

**请不要下载 `Source code (zip)` 或 `Source code (tar.gz)`。** 这两个文件是给开发者的，普通用户下载后不能直接使用。

## 1. 使用前准备

你需要：

- Windows 10 或 Windows 11 的 64 位 x64 电脑；
- Microsoft Edge 或 Google Chrome 浏览器；
- 至少 2 GB 可用磁盘空间；
- 如果要同步官网进度，准备自己的大观园登录码，或官网账号和密码；
- AI 功能是可选的，没有 API Key 也可以正常刷题和同步。

不需要安装 Git、Node.js、Python 或浏览器扩展。

## 2. 下载程序

1. 点击本页上方的蓝色下载链接。
2. 浏览器开始下载 `DaguanMath-windows-x64.exe`，文件大约 350 MB，请等待完全下载。
3. 如果浏览器提示“不常下载”或“可能有风险”，请先确认地址为 `github.com/Evan26Ma/daguan-cxy-local`，然后选择“保留”。
4. 打开电脑的“下载”文件夹，找到这个 EXE。为了方便以后使用，可以把它移到桌面或“文档\大观园”文件夹。

不要从网盘、聊天群或不明网站下载别人重新打包的版本。

## 3. 第一次启动

1. 双击 `DaguanMath-windows-x64.exe`。
2. 如果 Windows 显示“Windows 已保护你的电脑”，这是因为程序暂时没有购买代码签名证书。确认文件来自上面的 GitHub 页面后，点击“更多信息”，再点击“仍要运行”。
3. 会出现一个黑色窗口。这是大观园的本地服务，**使用期间不要关闭它**。
4. 第一次启动需要解压内置题库，可能要等几秒到一分钟。
5. Edge 或 Chrome 会自动打开大观园页面。地址一般以 `http://127.0.0.1:8080/` 开头。

`127.0.0.1` 表示你自己的电脑，不是可疑网站。如果 8080 端口已被其他程序使用，地址可能变成 8081、8082 等，这也是正常的。

黑色窗口如果显示 `ExperimentalWarning`，这是程序底层的 Node.js 单文件运行提示，不代表安装失败。浏览器能正常打开题库就可以继续使用。

## 4. 不配置账号，也可以先刷题

官网同步和 AI 都不是启动程序的必要条件。想先看看界面时：

1. 在首页选择高等数学、线性代数或概率统计。
2. 继续点击章节，直到进入具体小节和题目。
3. 点击“显示答案”查看解析。
4. 根据情况标记“未开始”、“学习中”、“已掌握”、“易错”或“收藏”。

这些操作会自动保存在本机，不需要手动点击“保存”。

## 5. 首次配置官网同步（可选）

如果希望把大观园官网的掌握状态和收藏带到本地，或者把本地进度同步回官网，请按下面操作。

### 第 1 步：打开配置向导

1. 回到大观园首页。
2. 找到“数据同步中心”。
3. 点击“同步进度”。
4. 第一次使用时，页面会自动进入“配置官网同步”向导。

### 第 2 步：检查本地中控台

页面应该显示本地服务正常。点击“服务正常，下一步”。如果显示服务异常，先检查黑色窗口是否已被关闭。

### 第 3 步：登录大观园

两种登录方式二选一：

- 有登录码：只填写“登录码”；
- 没有登录码：填写“账号”和“密码”。

点击“保存并登录”。看到“登录成功”后再继续。登录信息只提交给你电脑上正在运行的本地中控台；不要把登录码、密码或 Token 发给其他人。

### 第 4 步：先做只读测试

点击“测试读取”。这一步只读取官网的掌握状态和收藏，不会修改官网数据。看到读取成功后继续。

### 第 5 步：导入官网进度

点击“导入官网进度”。系统会先自动备份，再把官网掌握状态和收藏导入本地。看到“首次同步完成”后，点击“开始刷题”。

## 6. 以后怎样同步

日常使用时：

1. 点击首页“同步进度”。
2. 系统先做只读检查，显示官网和本地各有多少道题需要更新。
3. 看清页面上的同步方向和题目数量。
4. 确认没问题后，点击“确认同步”。

同步前会自动备份。掌握状态、收藏和最近学习位置可参与同步；易错标记、题目批注、AI Key、AI 服务配置和聊天历史永远不会上传到官网。

## 7. 配置 AI 解题（可选）

不配置 AI 不影响刷题。要使用 AI，你需要先从自己选择的 AI 服务商获得以下三项：

- API 根地址，例如 `https://api.example.com/v1`；
- API Key；
- 模型名称。

API Key 不是大观园密码，也不是 AI 网站的普通登录密码。不要把密码填进 API Key 输入框。

1. 打开左侧“工具区”。
2. 点击“界面设置”。
3. 向下找到“AI 服务档案”，点击“添加服务”。
4. “名称”可以随便写一个方便识别的名字。
5. 填写服务商提供的“API 根地址”和“API Key”。
6. 填写服务商提供的模型名，然后点击“保存服务”。第一次保存前必须先填一个模型名。
7. 在已保存的服务卡片上点击“编辑”。如果想确认可用模型，点击“获取模型列表”；如果接口不返回列表，保留手动填写的模型名即可。
8. 点击“测试连接与文本”。只有需要让 AI 看题目图片时，才需要点击“测试视觉能力”。
9. 测试通过后点击“取消”关闭编辑表单；如果修改了模型名，则再点击“保存服务”。
10. 进入一道题，点击题目操作栏里的“AI 解答”，输入问题后点击“发送”。

API Key 只保存在本机。截图求助时，请先遮住 API Key、大观园登录码、账号和密码。

## 8. 以后怎样打开和关闭

打开：双击保存好的 `DaguanMath-windows-x64.exe`。

关闭：先关闭浏览器页面，再关闭黑色运行窗口。只关闭浏览器页面不一定会停止本地服务。

如果不小心同时双击了两次，程序通常会复用已经打开的服务。保留一个正在运行的黑色窗口即可。

## 9. 数据保存在哪里

题库程序和个人数据默认保存在：

```text
%LOCALAPPDATA%\DaguanMath
```

完全不懂路径时，可以按键盘上的 `Win + R`，粘贴 `%LOCALAPPDATA%\DaguanMath`，再按回车。

请不要随意删除其中的 `data` 文件夹。删除前先在同步中心的“高级选项”中导出本地数据。

## 10. 怎样更新

1. 打开 [GitHub Releases](https://github.com/Evan26Ma/daguan-cxy-local/releases/latest)。
2. 下载新的 `DaguanMath-windows-x64.exe`。
3. 先关闭旧版的黑色运行窗口。
4. 用新 EXE 替换旧 EXE，然后双击新版。

更新 EXE 不会删除 `%LOCALAPPDATA%\DaguanMath\data` 里的刷题进度和配置。

## 11. 遇到问题怎么办

### 双击后什么都没发生

- 检查文件是否已经完全下载，大小应在 350 MB 左右；
- 检查浏览器或 Windows 安全中心是否拦截了文件；
- 不要直接在 ZIP 压缩包里运行；
- 不要关闭杀毒软件或 Windows Defender，只需核对 GitHub 来源和 SHA256。

### 黑色窗口出现了，但浏览器没打开

先等待一分钟。如果仍然没打开，查看黑色窗口里显示的地址，将它完整输入 Edge 或 Chrome 的地址栏。

### 页面显示“无法访问”

检查黑色窗口是否还开着。如果已关闭，重新双击 EXE。如果窗口中显示 8081 或其他端口，不要手动改回 8080。

### 登录失败

先确认登录码是否过期，或官网账号和密码是否正确。回到同步中心，点击“重新运行配置向导”再试一次。登录失败不会删除已有的本地刷题进度。
