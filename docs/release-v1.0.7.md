# 大观园数学桌面版 v1.0.7

新版 AI 解析支持展开到学习区约 55%，保留题目并排阅读；普通宽度与展开宽度分别管理，两种状态都支持拖宽。左侧导航可手动收起并记住选择，打开 AI 不自动改变导航。

服务选择、流式开关及私人上下文选项收入设置菜单；启用私人上下文时显示状态提示。回答占满正文宽度，增加行高与段落间距，长公式局部滚动。追问输入框保持在右下角并随输入增高。

新发起的完整解答按“答案 → 简短思路 → 详细推导 → 方法与易错点”组织；提示模式继续避免剧透，历史回答保持原文。实际标题提供段落跳转，向上阅读时暂停流式跟随并提供“回到最新内容”。单题和连续模式切换保留对话、草稿、生成状态与阅读位置。

此版本也包含主分支自 v1.0.6 后加入的单选自动判题与学习状态更新。没有新增服务 API、迁移用户数据或调整旧版布局。

## 验证

- AI 浏览器、新版核心与兼容、双界面及 UI 契约相关测试通过；服务实例与 Electron 安全测试通过。
- 人工检查 1920×1080、1366×768、小窗口及字体放大布局。
- 打包后的 Electron 1.0.7 使用临时数据目录启动，验证导航收起、55% 展开和草稿保留；包内新版文件与源码一致。
- 修复浏览器测试随机分配禁用端口和同步准备过程的竞态，后台跨窗口同步测试复测通过。按用户要求停止后续全量测试，不声明最终全量通过。
- 题库校验通过：6521 题、6521 个唯一题号；仍有 41 张题图缺失警告。
- 正式安装器在干净 Windows 用户配置下的安装与升级未实测。本次验证不读取或修改日常学习数据。

## 下载与更新

Windows x64 桌面资产为 `DaguanMathDesktop-Setup.exe`、`DaguanMathDesktop-1.0.7-full.nupkg` 与 `RELEASES`，每项附 `.sha256` 校验文件。安装器沿用未签名发行方式。

已安装桌面版可检查更新，安装完成后才能看到新界面；工作树修改不会直接更新已安装程序。
