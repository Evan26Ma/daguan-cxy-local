# 大观园数学桌面版 v1.0.16

本版修复 [issue #7](https://github.com/Evan26Ma/daguan-cxy-local/issues/7)：把官网新增的「线代严选题」同步进本地题库。题单是官网独立于分类树的显式题序，本地版此前既没有这道题单，线性代数「严选」范围也是 0 题。

## 功能范围

- 线性代数下新增「线代严选题」目录，按官网题单目录保留行列式、矩阵、向量、方程组、特征值与特征向量、二次型、数学一专项七章及原稿题序，共 376 题。
- 题单内 14 道官网新题已进入本地分片；其余 362 道复用原有题目与学习记录，不复制题号。
- 官网题库由 6,730 题更新到 7,211 题；其中 1 道被官网标记为“答案待补充”的无效单选题跳过，实际写入 7,210 道；加本地专有题库 389 道，合计 7,599 道唯一题目。
- 修复官网分类接口不再返回“历年真题”“模拟卷”两个根分类导致的同步失败。同步现在会按题目自带的 `category_full_path` 重建缺失分类，并沿用上一版题库的分类处理官网临时清空分类的老题。
- 修复自动更新题库后 `.jpeg` 等图片无法从随包资源回退的问题；同步与静态资源服务都按真实扩展名处理。

## 数据与图片

- 官网新追加的“原始参考答案”扫描图需要登录令牌。本次构建没有 `DAGUAN_ASSET_TOKEN`，因此 1,688 道题的该图片段落已省略，保留原有文字解析与答案；未省略的题目仍提示 95 张题图缺失。
- 题单中仅 12371（姜晓千真题同源150·例60）原本带 1 张原始答案图，已按同一规则省略，题目文字与答案正常显示。
- 讲解视频映射随官网下架题目退休 8 条记录、3 个题号，活动映射保留 9,783 条、6,031 道题。

## 验证

- `npm test`：333 项，332 通过、1 失败、0 取消、0 跳过。唯一失败是主线既有解析数据契约：`#7947 不在题库 id_index 里`，未修改数据掩盖失败。
- `npm run verify`：7,599 道唯一题目通过，提示 95 张题图缺失。
- 新增 3 项回归：隐藏分类根重建、官网题单注入与题序、缺图时“原始参考答案”段落清理。
- 真实浏览器验收：新版界面进入“线性代数 → 线代严选题”显示 376 题，七章计数为 40/75/31/73/64/71/22；切换到“严选”范围后线性代数与题单仍为 376 题；打开新题 12371 正常显示题干与答案，页面脚本错误为 0，破图为 0。
- 全部验证使用 F 盘隔离数据目录与独立浏览器 profile，没有读取或写入真实学习数据。
