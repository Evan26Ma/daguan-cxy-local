## Gate 5 修复

### 夜间主题底色与文字

按已保存的 `orange-night` 设置重开新版后，题库/阅读/设置所使用的主题变量已生效：应用背景 `#191B1C`、阅读面 `#242729`、主要文字 `#F5F2EB`、辅助文字 `#C1C1BA`。检查时发现题库目录里的原生按钮没有继承主题文字色，浏览器默认黑字落在暗底上；搜索输入也没有显式背景/前景，保留了白底。现已给目录按钮指定 `var(--text-primary)`，并给橙黑主题的 input / textarea / select 指定暗阅读面、明亮文字和控制边框色。已检查橙黑题库目录、搜索框、单题正文和设置卡片截图；题图保留原图白底。

主题预览行为仍按“预览草稿、应用保存、取消回滚”处理。离开外观设置后题库按已保存主题恢复，所以最终主题回归使用已保存的 `orange-night` 值，而非只点预设但没有按“应用”的草稿状态。

### 长公式搜索摘要

搜索结果中的纯文字仍保留短摘要样式；含数学表达式的摘要现在标记为 `has-math` 并解除两行/高度截断，避免 KaTeX 公式被截在中间。真实长题 99000016 的结果包含 5 组 KaTeX，(1)、(2)、(3)、(4)、(5) 内容全部能在结果卡片中查阅；原题题干为 531 字符。截图见 `theme-final/screenshots/long-formula-search-final.png`，结构化检查见 `theme-final/targeted-final-qa.json`。

### 新旧版壳版本

为让以上新版脚本和样式修改与缓存一致，当前新版引用 `app-new.js?v=109`、`styles-new.css?v=109`；共用 `ui-version.js?v=106`，Service Worker 使用 shell `daguan-shell-v111`、注册 URL `service-worker.js?v=111`。旧版 CSS/JS 仍为其现有 v89；旧版页面使用共用版本脚本 v106。入口、Service Worker 清单与静态版本契约测试已同步。
