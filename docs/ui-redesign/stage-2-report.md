## API 调用清单

### AI 服务

**POST** `/api/ai/chat`

```json
{
  "messages": [
    {"role": "system", "content": "..."},
    {"role": "user", "content": "..."}
  ],
  "apiKey": "sk-...",
  "baseUrl": "https://api.example.com/v1",
  "model": "gpt-3.5-turbo"
}
```

**响应**：Server-Sent Events (SSE) 流式返回

```
data: {"choices":[{"delta":{"content":"文本片段"}}]}
data: [DONE]
```

### 其他接口

- **静态资源**：题库 JSON、图片、视频映射均通过静态文件服务

## 双版本兼容

### 入口逻辑

1. **`/` 或 `/index.html`**
   - 读取 `daguan_version_preference`
   - `new` → 加载新版（`index-new-backup.html` + `app-new.js`）
   - `old` → 重定向 `/legacy.html`
   - 缺失/损坏 → 默认 `new`

2. **`/legacy.html`**
   - 强制旧版
   - 不受版本偏好影响

3. **URL 参数**
   - `?ui=old` → 显式旧版，写入偏好
   - `?ui=new` → 显式新版，写入偏好
