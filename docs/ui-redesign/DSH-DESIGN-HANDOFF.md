### 二、用户要解决的问题

这轮的目标是让新版**明显区别于旧大观**，并有一致、鲜明、耐看的数学学习产品气质。它应兼具“专注做题的阅读舒适度”和“进入产品时能记住的设计感”。先前的明亮浅色、橙色、数学几何方向可以保留或重构，但不要把“橙色面积更大、卡片更多”当作设计感。旧版必须继续存在，不能靠更换旧版样式来制造差异。

以下是从现有截图与代码观察到的**待你验证的症状**，不是预设解法：

- 桌面题库同时有应用侧栏和 256px 目录栏，视线被两层导航分割。目录把大量不同深度的节点直接铺开；代码中的父项点击主要是旋转箭头，子节点没有随层级真正收放。右侧又把章节平铺成等高长列表，重复左栏信息，缺少“现在位于哪里、这一层能做什么”的清晰解释。
- 右侧每行几乎只有名称和题数，行距、字重、分隔线反复出现，但类别、分组、近期位置、进入练习的动作没有形成可扫读的层级。某些父级/叶级混在同一列表，数据本身有深度，界面却接近数据库表。
- 手机题库把“目录、搜索、筛选”三个控件挤在一行，搜索输入窄；目录作为抽屉与列表关系不直观。筛选页虽然能用，但内容较长，已选条件、返回结果和重置动作的反馈弱。
- 首页用大块橙色主视觉加规则六宫格，视觉重心单一；数学几何标记已经有雏形，但品牌节奏还没有扩展到目录、题目和其他页面。
- 做题页排版比上一轮稳定，但短题下方留下大量空白，顶部元信息与行动关系弱；它应安静、适合长时间阅读，同时让人感觉是经过设计的学习界面。长公式、图片、解析、视频与 AI 打开时不能因追求装饰而受损。
- 顶栏、侧栏、列表、按钮、图标、数字和数学符号的粗细/尺寸/色彩需要更统一的规则。请指出真实证据，不要把主观印象冒充可测的错误。

题库功能现在已经接入真实 `search_index.json`：关键词、来源类别、年份、题型、帕拉迪宇/李艳芳/没咋了筛选、结果分页和点击入题都可用。来源是界面分组而非逐字原始来源。设计不能靠隐藏这些功能来“简洁”，也不能假造难度、正确率、学习时长或进度统计。若想用进度或推荐位，先确认现有数据能提供，再定义无数据状态。

### 三、设计方法与决策要求

先完成**诊断**，再做方案。以截图、真实浏览器和代码数据结构为证据，绘制当前题库的信息层级与四条路径：①从科目进入章节并开始做题；②在多级目录内定位一个叶章节；③搜到一题并打开；④组合筛选后返回题库并保留上下文。指出每条路径具体哪里迷失、重复或费力，并区分视觉问题与交互/信息架构问题。

接着提出**至少两个真正不同**的视觉方向。每个方向都要有名称、核心隐喻、版面骨架、字体与数字处理、主辅色比例、几何/图形原则、题库目录方案、手机方案、与旧版的关键差异及风险。不要只给两套配色。请推荐其中一个，说明为什么它更适合长时间数学学习，以及它如何避免普通后台管理界面和营销落地页的模板感。你可以偏离原设计稿的视觉细节，但每处偏离要指出带来的收益和兼容成本。

在推荐方向上做**可实施设计稿**。视觉稿既要看完整页面，也要看真实内容：很深的章节树、名称很长的章节、零题/少题章节、长公式、图片题、已有学习记录、无记录、搜索 0/1/很多结果、多个筛选项、AI 展开。桌面 `1440×900`、手机 `390×844` 必须有；同时定义 `1280×800`、`1024×768`、`360×800` 的转折规则，解释导航、目录、题面、AI 面板如何在各尺寸共存。若制作 HTML 样板，请使用可辨识的真实题库文案与真实长公式，不要用 lorem ipsum 或假统计；样板放在隔离目录，明确它不是产品代码。

设计稿需要以下规格，达到另一名实现者无需自行猜主要视觉决策的程度：

1. **设计系统**：字体栈与字重、中文正文/数学/数字/元信息字号及行高；色值和使用比例；阅读面与背景；间距尺度；页面网格、最大宽度、栏宽；圆角、边线、阴影、图标、焦点与状态；明暗及护眼主题；数学几何元素如何出现及何时不出现。给出 token 表与正反例。
2. **题库详细蓝图**：应用导航与题库目录的关系；目录层级收放、当前路径和选中态；父级、叶级、章节概览、题目结果的不同呈现；搜索位置、输入反馈、结果摘要、筛选入口与已选条件；题数、来源、讲师信息的位置；手机目录与筛选如何开关、滚动和返回。给出每种状态的线框/高保真稿与交互说明。
3. **全站页面**：首页、做题收起与答案展开、视频、AI 展开、批注、复习、笔记、记录、工具、设置。每页说明首屏主次、用户下一步、真实数据和空状态，以及与同一视觉语言的连接。优先完成题库，不要只在题库做一套与其他页脱节的“皮肤”。
4. **交互规格**：鼠标、键盘、触摸与 200% 缩放；菜单/筛选/弹层开启与关闭；页面跳转后保留搜索、筛选和目录上下文；加载、空、错误、保存中/失败、离线、受限预览；减少动效设置。写清楚点击目标、状态迁移、动画时长与必要的滚动行为。
5. **可访问与数学阅读**：文字/按钮对比度、触控目标、语义层级、焦点顺序、屏幕阅读器名称；长公式局部滚动、图片放大、答案长度变化、AI 打开后的题目最小可用宽度。尽量把“舒适”化为可检查指标。
6. **落地交接**：逐页/逐组件实现顺序、涉及的主要现有文件、能复用的状态与 API、风险最高的改动、每阶段可独立验收的截图与操作清单。明确旧版只作为对照和兼容对象，不能被新版 CSS 影响。

### 四、不可破坏的现有能力

保留新版默认入口、旧版独立入口及版本切换；两版共享学习数据，外观偏好分开。保留题库格式、题号、业务 API、收藏、掌握、易错、批注、题目位置、AI 草稿、组卷/导出/备份/恢复/官网同步入口及预览权限边界。三位讲师的视频映射与分集/时间参数、当前 AI 档案接口及“完整解答”教学提示都必须继续可达。题目默认单题并可切列表；旧版维持其默认列表与完整功能。应用缓存与 Windows 启动行为不因新界面设计改变。真实 AI 调用和官网写入不在设计验证中执行。
