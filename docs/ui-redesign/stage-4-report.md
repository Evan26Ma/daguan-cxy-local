## 本轮修复的 bug（回归发现，共 6 个）

### 功能性 bug（3 个）

1. **新版页面从未注册 Service Worker**：app-new.js 缺少 `register` 调用。修复后离线可用。
2. **SW 预缓存清单重复项致离线整体失效**：`marked.min.js` 在 SHELL 出现两次，`cache.addAll` 抛错 → install 永久卡死。修复后 v104 实测：activated、24 项缓存、离线 reload 应用可用。
3. **版本切换未接入 ui-version.js 机制**：自造键无效。已对齐 `daguan_ui_version_v1` + `uiSwitch=1`；批注落盘改 `markdown/updated_at/history` 格式与旧版互通（读取端归一化兼容）。

### 真实点击测试暴露的 bug（3 个，此前 evaluate 直调测不出来）

4. **科目卡片点击无反应（用户实测发现）**：内联 onclick 传字符串 id，`findCategoryById/findChapterById` 严格相等（数字===字符串）失败后静默返回。修复：统一 Number 宽松比较。
5. **手机端题库目录抽屉无打开入口**：目录树在 <1024px 是 fixed 抽屉（left:-280px），但页面上没有触发按钮，手机用户无法进入章节。修复：新增「目录」开关按钮（桌面隐藏）、遮罩、进章节后自动收起。
6. **手机端 AI/批注面板打开后在屏幕外**：JS 用 `closed` 类显隐，手机 CSS 却用 `open` 类滑入——"打开"后面板停留在视口右侧外，用户看不到、关闭按钮点不到。修复：显隐统一由 `closed` 类驱动（transform 滑入/滑出）。
