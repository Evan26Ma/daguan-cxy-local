## 核心验收标准

### 设计系统符合度

| 项目 | 要求 | 验证方法 |
|-----|------|---------|
| 品牌橙 | #FF6A1A | 首页继续区背景、按钮 |
| 字体 | Segoe UI Variable / Microsoft YaHei UI | 检查任意文本 |
| 题干字号 | 18px/32px | 做题页题目正文 |
| 按钮圆角 | 10px | 任意按钮边缘 |
| 面板圆角 | 16px | 卡片边缘 |
| 导航展开 | 208px | 桌面侧边栏宽度 |
| AI 面板 | 400px | AI 展开页右侧宽度 |

### 必须消除的现状

- ❌ 无题册风衬线字体（中文应为无衬线）
- ❌ 无巨大淡色题号
- ❌ 答案/解析不应各套灰盒
- ❌ 不是简单给旧页面盖橙色

### 技术约束

- ✅ 纯 HTML/CSS/JS（无 React）
- ✅ 使用本地 KaTeX（web/vendor/katex.min.css）
- ✅ 未修改 index.html、legacy.html
- ✅ 未修改题库数据文件
- ✅ 独立在 web/ui-preview/ 目录
