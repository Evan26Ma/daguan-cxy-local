   - 输入框不触发真实 API 请求
   - 快捷提示按钮仅填充文本到输入框

2. **搜索功能为静态**
   - 题库搜索框为样式展示
   - 不连接真实搜索逻辑

3. **导航链接为相对路径**
   - 页面间跳转使用相对链接
   - 部分链接为 `#` 占位

4. **图片题使用 SVG 示意图**
   - 原题引用的图片路径为 `assets/0720b78ea277...`
   - 样板使用 SVG 绘制的几何示意图替代
   - 实际图片资源需在阶段 2 整合时处理
