# 学习手账与成长印章

新版「记录」页提供七日日期选择、往前回看、自选日期，以及当天练习片段。展开片段可查看题号、结果和题干，也可回到原题。原有「历史」页保留浏览记录、筛选和删除功能，首页学习战报保持原样。

配色、字体和圆角继承现有应用变量，包括 `--brand-orange`、`--brand-text-on-white`、`--bg-surface`，随朱红奶白、橙白、蓝砂、米黄护眼、橙黑夜间、薄荷实验及自定义配色变化；没有独立硬编码的预览配色。

## 数据口径

- 使用已有 `study-activity.json`，不引入新的持久化格式。`GET /api/study-activity/journal?end=YYYY-MM-DD&timeZone=...` 返回以指定日期结束的七个学习日；默认最近七天，沿用本地时区每天 04:00 分日。
- 与首页战报共用事件分类逻辑。一天内同题去重；首次学习当天为新题，以后为复习。单纯浏览、查看答案、收藏不计有效练习。学习状态标记也属于有效练习，不宣称全部是已作答题。
- 连续同章节、相邻事件间隔不超过 30 分钟组成练习片段，只显示开始时间，不推算学习时长。片段内同题去重，不同片段的题数可能重叠。
- 印章从真实事件推导：首次练习、首次独立重做答对错题、新题 50/100/500/1000、累计练习 7 天、攻克 10 道不同错题。显示首次达到目标的学习日，回看过去不会撤销成就。旧进度不补造日期或成就。

## 模块与异常处理

`web/study-journal.js` 是显式依赖工厂，接收学习活动客户端、题库查询、安全 Markdown 渲染和导航回调。入口 `UIRenderer.renderRecords()` 仅负责挂载；`web/study-journal.css` 随新版加载，并纳入 Service Worker 与桌面包验证。

题干按需读取，进入页面前经过现有安全渲染。章节名等文本转义后显示，不接收内容中的操作属性。每个片段首批显示 30 题，列表首批显示 20 个片段，其余可继续加载。

学习事件通知触发更新；无数据变化不重绘，避免打断展开阅读和键盘焦点。读取失败保留当前已显示内容并提供刷新按钮；已有离线队列保持不变，提示统计可能未包含待同步事件。重新打开页面但服务不可用时明确报错，不伪造空记录。

验证用例：`test/study-journal.test.mjs`、`test/study-journal-browser.test.mjs` 与 `test/desktop-package.test.mjs`。浏览器用例需 Playwright Chromium，缺少环境时失败；数据与截图位于 `F:\AI\tmp`。运行 `npm test` 和 `npm run verify`。
