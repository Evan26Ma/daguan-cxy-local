# 大观园数学桌面版 v1.0.8

修复新版界面选择 150% 字号后，点击目录章节恢复成原来字号的问题。字号选择后立即保存，切换目录、进入题目及刷新页面均保留所选字号；设置页明确提示自动保存。颜色和主题仍使用原有的应用、取消预览流程。

AI 面板拖宽上限随可用学习区宽度调整，宽屏可继续向左拖宽，同时为题目区保留至少 360px。新版脚本和离线缓存版本同步更新。

- 全量测试首次运行 250 项：249 项通过，1 项因缺少默认 Playwright 浏览器而无法启动。指定本机 Chrome 后，该浏览器测试单独重跑通过；没有跳过项目。

- 包内新版脚本与源码在统一换行后一致。
- 题库验证通过：6521 题、6521 个唯一题号；仍有既有的 41 张缺图警告。
- 正式安装器在干净 Windows 用户配置下的安装及升级未实测。

## 下载与更新

Windows x64 桌面资产为 `DaguanMathDesktop-Setup.exe`、`DaguanMathDesktop-1.0.8-full.nupkg` 与 `RELEASES`，每项附 `.sha256` 校验文件。安装器沿用未签名发行方式。

已安装桌面版可检查更新并安装；源码修改需要安装或更新后才进入已安装程序。
