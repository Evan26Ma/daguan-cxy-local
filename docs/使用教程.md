# 大观园本地数学题库使用教程

## 1. 新电脑第一次使用

### Windows

双击项目根目录的 `启动本地题库.cmd`。脚本会自动：

1. 检查 Node.js 20；
2. 没有 Node.js 时下载便携运行时并校验；
3. 安装项目依赖；
4. 启动本地中控台；
5. 自动打开 `http://127.0.0.1:8080/`。

请保持启动窗口运行。关闭窗口会停止本地服务。

### 打包成一个 exe

如果要给新电脑直接使用，不想安装 Node.js，可以在有 Node.js 20.12+ 的电脑上执行：

```powershell
npm run package:windows
```

然后把 `dist/大观园数学题库.exe` 复制到新电脑，双击即可。第一次启动会把内置题库释放到 `%LOCALAPPDATA%\DaguanMath\app`，个人数据保存到 `%LOCALAPPDATA%\DaguanMath\data`。

### Linux

```bash
bash scripts/install-linux.sh
```

安装脚本会创建 `daguan-math.service` 用户服务。查看日志：

```bash
journalctl --user -u daguan-math.service -f
```

### Docker

```bash
docker compose -f deploy/docker-compose.yml up -d --build
```

访问 `http://127.0.0.1:8080/`。数据会保存到项目根目录的 `data/`。

## 2. 配置大观园同步

1. 打开首页的“设置同步”；
2. 第一步确认本地中控台运行正常；
3. 输入大观园登录码；如果接口要求账号和密码，也可以同时填写；
4. 点击“保存并登录”；
5. 点击“测试读取”，确认能读取官网状态；
6. 点击“迁移本机进度”，把旧版浏览器中的进度合并到本地文件；
7. 完成配置。

不需要安装 Chrome/Edge 扩展，不需要打开大观园官网标签页。Node 中控台会直接调用官网 API。

登录 Token 保存在本机 `data/cxyonly-integration.json`，不会显示在网页、导出文件或日志中。

## 3. 日常同步

首页“数据同步中心”提供四个入口：

- **检查差异**：读取官网掌握、收藏、最近学习和活动，展示双向变化；
- **应用对账**：先备份并写入本地，再按预览计划写入官网并复读校验；
- **导出本地数据**：导出本地 Node 状态；
- **导出官网快照**：读取并保存当前官网状态。

启动服务后只检查本地中控台和登录状态，不会自动改写任何进度。请在“官网同步”中手动检查差异，确认后再应用双向对账。

上传官网默认不会自动执行，必须经过预览确认。写入前会生成备份到：

```text
data/cxyonly-backups/
```

## 4. 进度和题目导出

左侧“进度备份”仍可导出浏览器兼容 JSON，并支持导入旧版本备份。官网同步页面的导出按钮则导出 Node 中控台状态或官网快照。

题目 PDF 导出仍在题库页面中使用“导出 PDF”。

## 5. 界面主题和背景

点击顶部“界面设置”，或移动端底部的“外观”，可以切换：

- **官网浅色**：默认的蓝色工作台风格；
- **官网深色**：夜间刷题配色；
- **米黄色护眼**：保留原来的米黄色背景和深蓝色按钮；
- **自定义**：选择背景颜色，或导入一张本地 PNG、JPG、WEBP 图片。

背景图片最大 5MB，只保存到当前浏览器的 IndexedDB；它不会写入 `data/`、不会出现在进度 JSON，也不会上传到大观园。页面刷新后主题会自动恢复。

如果图片遮挡文字，可以调高“背景遮罩”或调整图片位置。点击“恢复官网默认”会清除本地背景并回到官网浅色，点击“恢复米黄色护眼”则回到护眼配色。

## 6. 故障排查

### 页面打不开

确认启动窗口仍在运行，并检查 `127.0.0.1:8080` 是否被其他程序占用。

### 登录失败

重新打开“设置同步”，确认登录码有效。如果大观园接口字段发生变化，需要更新 `local-server/cxyonly-client.mjs` 的登录适配。

### Token 失效

点击“重新配置账号”，重新登录即可。旧的本地刷题进度不会被清除。

### 官网暂时无法访问

本地题库仍可离线刷题。服务会把错误写入 `data/sync-history.jsonl`，不会覆盖上一次成功状态。

### 同步策略

新版不在启动时或后台定时改写官网/本地进度。只有在同步中心点击“检查差异”并确认“应用对账计划”后，才会执行双向写入；断网时刷题记录留在浏览器离线队列，恢复中控台后逐题重试。
