# 大观园本地数学题库使用教程

## 1. 新电脑第一次使用

### Windows

双击项目根目录的 `启动本地题库.cmd`。脚本会自动：

1. 检查 Node.js 20；
2. 没有 Node.js 时下载便携运行时并校验；
3. 安装项目依赖；
4. 启动本地中控台；
5. 自动打开 `http://127.0.0.1:8080/`。

请保持启动窗口运行。关闭窗口会停止本地服务。

### 一键安装包（推荐）

从 GitHub Releases 下载 `大观园数学题库-windows-x64.zip`，解压后双击 `安装大观园数学题库.cmd`。它会自动安装 Windows x64 单文件程序、创建桌面/开始菜单快捷方式并启动本地题库，不需要另外安装 Node.js。

适用设备：Windows 10 22H2 或 Windows 11 64 位 x64 台式机、笔记本和教学机；推荐 Edge 或 Chrome、8 GB 内存和至少 2 GB 可用空间。32 位 Windows、原生 ARM64、Firefox 和手机端不在本安装包支持范围内。

### 自行打包成一个 exe

如果要给新电脑直接使用，不想安装 Node.js，可以在有 Node.js 20.12+ 的电脑上执行：

```powershell
npm run package:windows
```

然后执行 `npm run package:windows:release` 生成完整 ZIP；也可以把 `dist/大观园数学题库.exe` 复制到新电脑直接运行。第一次启动会把内置题库释放到 `%LOCALAPPDATA%\DaguanMath\app`，个人数据保存到 `%LOCALAPPDATA%\DaguanMath\data`。

### Linux

```bash
bash scripts/install-linux.sh
```

安装脚本会创建 `daguan-math.service` 用户服务。查看日志：

```bash
journalctl --user -u daguan-math.service -f
```

### Docker

```bash
docker compose -f deploy/docker-compose.yml up -d --build
```

访问 `http://127.0.0.1:8080/`。数据会保存到项目根目录的 `data/`。

## 2. 配置大观园同步

1. 打开首页的“同步教程”，确认同步范围和安全边界，再点击“开始首次配置”；
2. 第一步确认本地中控台运行正常；
3. 登录方式二选一：优先输入大观园登录码；没有登录码时填写官网账号和密码；
4. 点击“保存并登录”；
5. 点击“测试读取”，确认能只读获取官网掌握状态和收藏；
6. 点击“导入官网进度”，系统会先备份浏览器状态、本地状态和官网快照，再迁移官网状态；
7. 完成配置。

不需要安装 Chrome/Edge 扩展，不需要打开大观园官网标签页。Node 中控台会直接调用官网 API。

登录 Token 保存在本机 `data/cxyonly-integration.json`，不会显示在网页、导出文件或日志中。

## 3. 日常同步

首页“数据同步中心”只有一个主流程：

- **同步进度**：自动读取官网和本地变化，显示两边各有多少道题需要更新；
- **确认同步**：确认后先备份并写入本地，再按预览内容写入官网并复读校验；
- **高级选项**：导出本地数据、官网快照和 Android 兼容包。

启动服务后只检查本地中控台和登录状态，不会自动改写任何进度。日常操作顺序固定为：点击“同步进度”开始只读检查，核对一句话结果，涉及官网写入时点击“确认同步”。

同步范围：

- 双向同步掌握状态、收藏和最近学习位置；
- 官网历史活动只读取到本地；
- 易错标记、题目批注、AI Key、AI 服务档案和聊天历史永不上传官网。

上传官网默认不会自动执行，必须经过预览确认。写入前会生成备份到：

```text
data/cxyonly-backups/
```

## 4. 进度和题目导出

左侧“进度备份”仍可导出浏览器兼容 JSON，并支持导入旧版本备份。官网同步页面的导出按钮则导出 Node 中控台状态或官网快照。

题目 PDF 导出仍在题库页面中使用“导出 PDF”。

## 5. 界面主题和背景

点击顶部“界面设置”，或移动端底部的“外观”，可以切换：

- **官网浅色**：默认的蓝色工作台风格；
- **官网深色**：夜间刷题配色；
- **米黄色护眼**：保留原来的米黄色背景和深蓝色按钮；
- **自定义**：选择背景颜色，或导入一张本地 PNG、JPG、WEBP 图片。

背景图片最大 5MB，只保存到当前浏览器的 IndexedDB；它不会写入 `data/`、不会出现在进度 JSON，也不会上传到大观园。页面刷新后主题会自动恢复。

如果图片遮挡文字，可以调高“背景遮罩”或调整图片位置。点击“恢复官网默认”会清除本地背景并回到官网浅色，点击“恢复米黄色护眼”则回到护眼配色。

## 6. 故障排查

### 页面打不开

确认启动窗口仍在运行，并检查 `127.0.0.1:8080` 是否被其他程序占用。

### 登录失败

重新运行“首次配置向导”，确认登录码有效。如果大观园接口字段发生变化，需要更新 `local-server/cxyonly-client.mjs` 的登录适配。

### Token 失效

点击“重新配置账号”，重新登录即可。旧的本地刷题进度不会被清除。

### 官网暂时无法访问

本地题库仍可离线刷题。服务会把错误写入 `data/sync-history.jsonl`，不会覆盖上一次成功状态。

### 同步策略

新版不在启动时或后台定时改写官网/本地进度。日常只需点击“同步进度”：应用会先进行不会修改数据的检查，展示一句清晰结论；只有涉及上传官网时才需要点击“确认同步”。断网时刷题记录留在浏览器离线队列，恢复中控台后逐题重试。
