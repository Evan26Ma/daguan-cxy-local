# 大观园本地数学题库使用教程

## 1. 新电脑第一次使用

### Windows

普通用户请[下载 Windows 桌面版](https://pan.baidu.com/netdisk/share?surl=VrW0Z-ThDSM7f_xx7uCUZw)（百度网盘提取码：`dgy1`），不需要安装 Node.js。安装完成后会自动创建桌面和开始菜单快捷方式；关闭学习窗口会缩到系统托盘，服务由桌面程序管理。浏览器安装包已停止维护，现有用户可参阅[迁移说明](百度网盘下载与引导页配置.md)。

从下载到首次同步、AI 配置的逐步说明，见 [Windows 新手安装与配置教程](Windows新手安装与配置.md)。

开发者如需从源码启动，可双击项目根目录的 `启动本地题库.cmd`；该方式会检查 Node.js、安装依赖并打开本地页面。

适用设备：Windows 10 22H2 或 Windows 11 64 位 x64 台式机、笔记本和教学机；推荐 Edge 或 Chrome、8 GB 内存和至少 2 GB 可用空间。32 位 Windows、原生 ARM64、Firefox 和手机端不在本安装包支持范围内。

### 维护者本地兼容构建（非公开发行包）

仓库保留独立浏览器容器构建脚本，供维护者进行本地兼容性测试。它不是当前公开提供的 Windows 安装版本；普通用户请使用 Electron 桌面版安装器。需要测试时，在有 Node.js 20.12+ 的电脑上执行：

```powershell
npm run package:windows
```

然后执行 `npm run package:windows:release` 生成本地测试 ZIP。构建产物仅供维护者本机测试，不作为当前 Release 的下载包。数据保存到 `%LOCALAPPDATA%\DaguanMath\data`。

### Linux

```bash
bash scripts/install-linux.sh
```

安装脚本会创建 `daguan-math.service` 用户服务。查看日志：

```bash
journalctl --user -u daguan-math.service -f
```

### Docker

```bash
docker compose -f deploy/docker-compose.yml up -d --build
```

访问 `http://127.0.0.1:8080/`。数据会保存到项目根目录的 `data/`。

## 2. 配置大观园同步

从首页的「同步进度」或工具页的「官网同步向导」进入页面内流程。新版与旧版都按四步操作：

1. **登录**：填官网登录码；如果使用账号密码，改填账号和密码。登录失效时回到这一步重新验证。
2. **只读检查**：点击「检查同步内容」。应用会读取本机与官网状态，此时不会写入。
3. **核对变化**：看清「官网 → 本地」和「本地 → 官网」的题目数，展开题号明细。有冲突时选择保留较新状态、以官网为准或以本地为准；改变策略后重新检查。
4. **确认写入**：只有你点击确认，才按当前预览写入。失败或预览过期时重新检查，再确认一次。

第一次同步也走上述流程。应用会在写入前保存本地及官网快照；官网同步不会在启动时自动上传。教程可以从首页或工具页打开，每一步能跳到对应页面，并记住未完成的位置。

不需要浏览器扩展，也不需要打开官网标签页。本地服务负责调用官网 API；登录 Token 不会返回网页或进入学习记录备份。

## 3. 日常同步

日常仍从首页「同步进度」进入同一个四步向导：

- **同步进度**：自动读取官网和本地变化，显示两边各有多少道题需要更新；
- **确认同步**：确认后先备份并写入本地，再按预览内容写入官网并复读校验；
- **高级选项**：导出本地数据、官网快照和 Android 兼容包。

打开应用只检查连接状态，不会自动改写进度。预览没有变化时无需确认写入；发生冲突或写入失败时按向导提示重试。

同步范围：

- 双向同步掌握状态、收藏和最近学习位置；
- 官网历史活动只读取到本地；
- 易错标记、题目批注、AI Key、AI 服务档案和聊天历史永不上传官网。

上传官网默认不会自动执行，必须经过预览确认。写入前会生成备份到：

```text
data/cxyonly-backups/
```

## 4. 进度和题目导出

在「工具」中下载本地 JSON 备份；旧版的「进度备份」也可导出或导入旧版本备份。更换设备前请保留备份文件。官网同步页面还能导出本地状态或官网快照。

题目 PDF 导出仍在题库页面中使用“导出 PDF”。

## 5. 在自己的其他设备使用

桌面版「设置 → 外网浏览器访问」可以手动开启临时地址。先设置至少 12 位访问密码；应用确认公网登录页可访问后才会显示地址。退出应用会断开连接，留在托盘则继续运行。

固定域名从「配置固定域名」进入页面内四步向导：自己购买域名并接入 Cloudflare、准备限定权限的 API 令牌、创建并检查 Tunnel/路由/DNS、取得已验证的地址。你需要自行完成购买与名称服务器修改。令牌只用于创建，本机只加密保存 Tunnel 运行令牌。已有固定配置时使用「连接 / 恢复」或「停用」，不要重复创建。

外网登录只能使用学习功能，密码和隧道管理仍由本机桌面版操作。新版和旧版页面都可从外网使用同一份本地记录。

## 6. 界面主题和背景

点击顶部“界面设置”，或移动端底部的“外观”，可以切换：

- **官网浅色**：默认的蓝色工作台风格；
- **官网深色**：夜间刷题配色；
- **米黄色护眼**：保留原来的米黄色背景和深蓝色按钮；
- **自定义**：选择背景颜色，或导入一张本地 PNG、JPG、WEBP 图片。

背景图片最大 5MB，只保存到当前浏览器的 IndexedDB；它不会写入 `data/`、不会出现在进度 JSON，也不会上传到大观园。页面刷新后主题会自动恢复。

如果图片遮挡文字，可以调高“背景遮罩”或调整图片位置。点击“恢复官网默认”会清除本地背景并回到官网浅色，点击“恢复米黄色护眼”则回到护眼配色。

## 7. 故障排查

### 页面打不开

确认大观园桌面版仍在运行；关闭窗口后可在系统托盘找到它。开发服务请检查本机端口是否被其他程序占用。

### 登录失败

回到页面内同步向导的「登录」步骤，确认登录码或账号密码有效。如果官网接口字段变化，需要更新 `local-server/cxyonly-client.mjs` 的登录适配。

### Token 失效

回到同步向导重新登录即可。旧的本地刷题进度不会被清除。

### 官网暂时无法访问

本地题库仍可离线刷题。服务会把错误写入 `data/sync-history.jsonl`，不会覆盖上一次成功状态。

### 同步策略

新版不在启动时或后台定时改写官网/本地进度。日常只需点击“同步进度”：应用会先进行不会修改数据的检查，展示一句清晰结论；只有涉及上传官网时才需要点击“确认同步”。断网时刷题记录留在浏览器离线队列，恢复中控台后逐题重试。
