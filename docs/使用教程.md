## 1. 快速上手（一键启动）

### Windows 用户（推荐）

1. 双击仓库根目录下的 **`启动本地题库.cmd`**；
2. 脚本将自动检测 Python 环境并启动本地 Web 服务（端口 `8080`），同时自动在默认浏览器中打开：
   ```text
   http://localhost:8080/
   ```
3. 刷题时请**保持黑色的命令行窗口开启**，刷题结束关闭窗口即可退出。

> **提示**：如果提示“未检测到 Python 环境”，请前往 [Python 官网](https://www.python.org/downloads/) 下载并安装 Python 3（安装时请务必勾选 **"Add python.exe to PATH"**）。

### Linux / macOS 用户

在终端中切换到项目目录并执行：

```bash
python3 -m http.server 8080 --directory web
```

然后在浏览器中打开 `http://localhost:8080/`。

### Docker 用户

如果你习惯使用 Docker，可以直接执行：

```bash
# Windows 可双击 启动本地题库-Docker.cmd
docker compose -f deploy/docker-compose.yml up -d --build
```

访问地址同样为 `http://localhost:8080/`。

## 2. 本地刷题与常用功能

- **数据纯本地**：题库、公式渲染器（KaTeX）、字体和刷题进度完全留在当前浏览器（LocalStorage / IndexedDB），**断网也能正常刷题**。
- **开始刷题**：点击首页的“从高等数学开始 →”或点击左侧导航栏展开章节分类。
- **刷题模式**：
  - **列表模式**：适合批量连续做题与自查。
  - **单题模式**：专注单道题，支持键盘快捷键：
    - <kbd>←</kbd> / <kbd>→</kbd>：上一题 / 下一题
    - <kbd>A</kbd>：展开 / 折叠答案与解析
    - <kbd>1</kbd> ~ <kbd>4</kbd>：选择对应的单选选项
- **标记状态**：每道题目支持标记“已掌握”、“需练习”、“完全不会”以及点击星标收藏，状态实时保存。
- **导出 PDF**：点击左侧“导出 PDF”，可选择勾选题、错题或当前分类，一键生成排版工整的打印版 PDF。

## 3. 进度备份与跨设备迁移

如果需要更换电脑、浏览器或重装系统：

1. 打开左下角 **“进度备份”**；
2. 点击 **“下载备份”** 保存 JSON 文件（或点击“复制备份 JSON”）；
3. 在新电脑/新浏览器打开本地题库，在“进度备份”中点击 **“选择备份文件导入”**，即可无缝恢复所有做题记录与收藏。

## 4. 配置官网同步（Chrome / Edge 扩展）

通过轻量级同步扩展，可实现本地进度与大观园官网（[https://www.cxyonly.fans/math](https://www.cxyonly.fans/math)）互通。**本地网页不会接触你的登录密码与 Cookie 凭证，所有通讯均在浏览器本地安全中转。**

### 步骤 1：安装扩展（仅需配置一次）

1. 打开 Chrome 或 Edge 浏览器，在地址栏输入：
   ```text
   chrome://extensions/
   ```
   （Edge 浏览器输入 `edge://extensions/`）并按回车。
2. 在右上角开启 **“开发者模式”**（Developer mode 开关）。
3. 点击左上角 **“加载已解压的扩展程序”**（Load unpacked）。
4. 选择本项目中的 `sync-extension` 文件夹完成加载。

### 步骤 2：登录官网

在同一浏览器中打开并登录官网：[https://www.cxyonly.fans/math](https://www.cxyonly.fans/math)，并**保持官网标签页处于打开状态**。

### 步骤 3：获取扩展 ID 并绑定

1. 点击浏览器右上角扩展栏中的“大观园数据桥接”图标；
2. 在弹出的扩展卡片上，点击 **“复制 ID”** 按钮；
3. 返回本地题库网页（`http://localhost:8080/`），点击首页 **“设置同步”**；
4. 将复制的扩展 ID 粘贴到配置向导中；
5. 点击 **“保存并检查连接”**，确认找到官网标签页；
6. 点击 **“测试读取官网数据”**，若显示官网题目状态数量，即表示配置成功。

浏览器不会允许普通网页直接替你安装扩展，也不会允许普通网页直接读取官网登录 Cookie。配置向导会自动打开扩展管理页和官网，但“加载已解压的扩展程序”和官网登录仍需要你在浏览器中确认。

## 5. 从官网读取与同步到官网

### 从官网读取进度到本地

- 在首页 **“数据同步中心”** 点击 **“从官网读取”**（也可以从左侧“官网同步”进入）。
- 如果尚未完成配置，按钮会先进入配置向导；完成后再次点击即可读取。
- 系统会先计算并展示预览（官网题目总数、将更新的掌握题数、将新增的收藏数）。
- 确认后将合并到本地。**规则说明**：官网未作答或未标记的项目**不会**清空本地已有记录，仅做增量安全合并。

### 将本地进度同步上传到官网

- 在首页 **“数据同步中心”** 点击 **“同步到官网”**（也可以从左侧“官网同步”进入）。
- 系统会展示变更统计（预计修改题目数）。
- 点击确认后：
  1. 扩展会**自动下载一份当前官网状态的备份 JSON** 到你的下载文件夹；
  2. 随后安全地将本地标记写入官网；
  3. 写入完成后给出成功提示。

## 6. 常见问题与故障排查

### Q1：为什么不能直接双击 `web/index.html` 打开？
现代浏览器的跨域安全策略（CORS）会阻止本地 `file://` 协议加载本地 JSON 题库数据和字体。请务必使用 `启动本地题库.cmd` 或 Python 静态服务器通过 `http://localhost:8080/` 打开。

### Q2：扩展显示“未连接”？
请确认已在同一浏览器的另一个标签页中打开了 `https://www.cxyonly.fans/math` 并且已正常登录。

### Q3：点击“打开扩展管理”没有反应？
出于安全限制，部分浏览器会拦截网页直接打开 `chrome://extensions/` 协议。此时请手动新建浏览器标签页，在地址栏输入 `chrome://extensions` 回车即可。

### Q4：同步安全吗？会泄露密码或被封号吗？
- 扩展代码开源且透明，只读取与写入题目 ID、掌握状态（mastered / needs_practice / not_known）、收藏和修改时间戳；
- 不会收集、存储或向任何第三方发送账号、密码或 Token；
- 每次写入前均会自动备份原站进度，防止意外覆盖。
