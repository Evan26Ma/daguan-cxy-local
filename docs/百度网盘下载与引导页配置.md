# 桌面版下载与浏览器版迁移

## 普通用户下载

[下载 Windows 桌面版安装器](https://pan.baidu.com/netdisk/share?surl=VrW0Z-ThDSM7f_xx7uCUZw)，百度网盘提取码 `dgy1`。安装后从开始菜单打开“大观园数学”。桌面版与旧浏览器安装包使用同一份 `%LOCALAPPDATA%\DaguanMath\data` 学习记录。最终浏览器迁移包中的按钮固定指向 [v1.0.2 桌面安装器](https://github.com/Evan26Ma/daguan-cxy-local/releases/download/v1.0.2/DaguanMathDesktop-Setup.exe)。

浏览器安装包已停止维护，公开下载页不再推荐。已经安装浏览器包的用户：先确认页面提示待同步记录已保存；如果保存失败，下载本机记录备份；然后安装并启动桌面版。桌面版会优雅停止可确认的浏览器服务并接管数据目录。不要手动删除正在运行的服务实例锁。

旧浏览器包不会自动更新。最后一个带迁移提示的浏览器包以[ZIP 迁移归档](https://github.com/Evan26Ma/daguan-cxy-local/releases/download/v1.0.2/DaguanMath-windows-x64.zip)和[单文件迁移归档](https://github.com/Evan26Ma/daguan-cxy-local/releases/download/v1.0.2/DaguanMath-windows-x64.exe)提供；SHA-256 见 [v1.0.2 发布说明](release-v1.0.2.md)。旧[百度网盘浏览器包链接](https://pan.baidu.com/netdisk/share?surl=VJwUxgElbURfw7Aj4Gpy4Q)提取码 `wweb`，在核对分享内容替换为最终包之前仍视为旧版，不推荐继续使用。

## 维护者更换下载入口

- 桌面版下载链接和提取码需同步更新 `web/landing.html`、`web/browser-retirement.js`、`web/index.html`、`web/legacy.html`、`README.md`、`docs/Windows新手安装与配置.md` 与 `docs/使用教程.md`。
- 最终浏览器迁移包的归档链接只保留在本文；若百度网盘分享链接发生变化，在这里更新归档地址和校验值，不要恢复公开下载页的浏览器主按钮。
- 构建正式安装器后，核对 GitHub Release 的目标远端、tag、`RELEASES`、完整 nupkg、Setup 和各自 SHA-256。上传分享文件后用无痕窗口检查链接及提取码。修改仓库文件本身不会更新已安装程序或线上页面。
