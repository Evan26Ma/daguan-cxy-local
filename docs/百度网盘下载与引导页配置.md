# 百度网盘下载与引导页配置

本文记录普通用户如何下载，以及维护者怎样替换引导页里的下载链接。Electron 桌面版与本地浏览器版是两个独立程序包、两个独立分享链接，不能把链接和提取码交叉使用。

## 给下载者：选哪个版本

| 版本 | 下载入口 | 百度网盘提取码 | 适合谁 |
|---|---|---|---|
| **Electron 桌面版（推荐）** | [打开 Electron 桌面版分享](https://pan.baidu.com/netdisk/share?surl=VrW0Z-ThDSM7f_xx7uCUZw) | `dgy1` | 大多数用户。下载 `.exe` 后安装，在独立桌面窗口学习；关闭窗口后可从系统托盘恢复。 |
| 本地浏览器版 | [打开本地浏览器版 ZIP 分享](https://pan.baidu.com/netdisk/share?surl=VJwUxgElbURfw7Aj4Gpy4Q) | `wweb` | 希望用 Edge/Chrome 窗口学习的用户。下载 ZIP、解压，再双击安装指引；它在本机启动服务并打开浏览器，不启动 Electron。 |

这两条链接分别指向 `DaguanMathDesktop-Setup.exe` 和 `DaguanMath-windows-x64.zip`。两者虽然共用 `%LOCALAPPDATA%\DaguanMath\data`，程序入口与窗口行为不同。百度分享接口确认两条链接均为永久有效（`period: 0`）。桌面安装包 SHA-256：

```text
2139a96a85cf3d5865acb3814ae4241edaa703b0e9ce95f86d327be15816f6ac
```

## 给维护者：更换下载链接或提取码

### 第一步：在百度网盘建立两份单独分享

1. 先把 Electron 桌面安装器和本地浏览器版 ZIP 分别上传到自己的百度网盘。不要把两个文件打成一个压缩包，否则用户无法单独选择版本。
2. 在网盘文件列表中分别选中一个文件，点击“分享”。每次只分享一个文件。
3. 有效期选“永久”（如果网盘界面没有永久选项，按实际可选期限创建，并在下方页面和教程里写清到期时间）。
4. 设置 4 位数字/小写字母提取码。Electron 桌面版和本地浏览器版使用不同的提取码。
5. 创建后复制各自的分享链接和提取码，先在无痕窗口打开链接，确认分别能看到正确的文件，再更新页面。

当前配置如下，后续重新上传文件时请用新生成的值替换：

```text
Electron 桌面版分享：https://pan.baidu.com/netdisk/share?surl=VrW0Z-ThDSM7f_xx7uCUZw
Electron 桌面版提取码：dgy1
本地浏览器版分享：https://pan.baidu.com/netdisk/share?surl=VJwUxgElbURfw7Aj4Gpy4Q
本地浏览器版提取码：wweb
```

### 第二步：修改引导页

在项目目录打开 `web/landing.html`，搜索 `pan.baidu.com/netdisk/share`。页面目前有三个下载位置：

- 首屏按钮：桌面版（推荐）；
- 页面底部主按钮：桌面版（推荐）；
- 页面底部次按钮：网页版本机服务包 ZIP。

每个下载按钮的 `href="..."` 是分享链接。把双引号里的完整 URL 换成同一版本的新链接；不要只替换 `surl` 后半段之外的地址，也不要把网页版地址贴到桌面版按钮。

提取码是按钮旁边显示的普通文字。桌面版目前是 `dgy1`，网页包目前是 `wweb`。分享链接和提取码必须成对更新；如果换了提取码，页面与 `docs/Windows新手安装与配置.md` 里的提取码也要一起改。

### 第三步：同步其他说明

为避免用户从不同入口看到旧地址，还要检查并同步更新：

- `web/index.html`：预览页中的桌面版下载入口；
- `web/legacy.html`：旧版预览中的桌面版下载入口；
- `README.md` 与 `docs/使用教程.md`：项目说明里的普通用户下载入口；
- `docs/Windows新手安装与配置.md`：两种版本的下载链接、提取码和安装步骤。

可以在项目根目录执行以下命令，查找仍残留的旧链接或旧提取码：

```powershell
rg -n "pan.baidu.com/netdisk/share|DaguanMathDesktop-Setup.exe|DaguanMath-windows-x64.zip|dgy1|wweb" README.md docs web
```

### 第四步：本机检查与发布

1. 用浏览器打开本地 `web/landing.html`，分别点击桌面版和网页版下载入口，确认地址不同、提取码对应。
2. 检查首屏明确写了“推荐”，底部也保留两个单独入口；手机宽度下两个按钮应能分开点击。
3. 运行 `git diff --check`，确认修改没有多余空白或冲突标记。
4. 提交并推送网页文件、README 和教程的改动后，再按项目现有网站发布流程更新线上引导页。**只改本地 HTML 不会自动改变网上页面。**
5. 发布后用无痕窗口再测一遍线上两条分享链接和提取码。百度网盘分享和网站发布是两件事：换了网盘文件，不代表线上引导页会自动更新。
