# 大观园数学桌面版 v1.0.15

本版修复 [issue #6](https://github.com/Evan26Ma/daguan-cxy-local/issues/6)：新版设置中更换主题后，点击题库会恢复原颜色。

## 修复行为

原实现只把所选颜色用于实时预览，“应用”按钮才保存；题库重绘时重新读取保存值，其他页面却继续显示预览，导致导航行为不一致。现在离开设置时保存当前外观，侧栏导航、顶栏首页及全库搜索均生效。“应用”可立即保存，“取消”仍撤销未保存的颜色，字号继续即时保存。

保存失败时保留设置页与当前预览并提示重试；取消到原保存值后可以直接离开，无需再次写入。前端脚本引用和离线缓存同步更新，避免升级后仍加载旧实现。

## 发布范围

候选从已提交主线 `ad14926c7c600e012488bfffea6f48b614c170e6` 在 F 盘独立工作树制作，未带入开发主目录中尚未提交的存储迁移、服务启动恢复、iOS 与官网同步改动。v1.0.13、v1.0.14 是未公开 GitHub Release 的本地候选，因此本次使用 v1.0.15。

相对上一公开版 v1.0.12，本版同时包含已合入主线的题库范围约束修复、答案自动刷新时保留展开与滚动位置、原生 PDF 题解、讲解视频映射更新、概率统计百宝书 230 题以及救命课选项补齐。题库现为 7,119 道唯一题目。

使用过 v1.0.14 自定义存储试用构建的用户应保留该候选；本版沿用公开主线存储方式，不含该试用功能，未验证从自定义存储试用安装升级。
