# 干净环境安装验证（VirtualBox 方案）

本文档定义正式安装器 `DaguanMathDesktop-Setup.exe` 在干净 Windows 环境中的安装验证流程。

背景：阶段 3/4 验收明确跳过了正式安装器在干净环境的安装验收（QA 使用了不同 Squirrel 身份 `DaguanMathStage4QA`，不等同于正式安装器验证），见 [desktop-stage4-report.md](desktop-stage4-report.md)。本文档补上这一环。

> 说明：微软原「Windows 11 开发机 VM」（90 天授权、VirtualBox 格式）下载页已于 2026 年下线
> （`developer.microsoft.com/en-us/windows/downloads/virtual-machines/` 现重定向至通用开发工具页）。
> 改用微软官网正式版 Win11 ISO 自建虚拟机：可装家庭版（与目标用户一致），不激活即可长期用于测试。

---

## 一、一次性环境准备（约 1 小时）

### 1. 安装 VirtualBox（装到 F 盘）

1. 到 [virtualbox.org](https://www.virtualbox.org/wiki/Downloads) 下载 **Windows hosts** 安装包（7.2+）。
2. 运行安装程序，**安装目录改到 `F:\VirtualBox\`**——本机 C 盘剩余空间不足 5GB，装 C 盘会失败。
3. 安装完成后打开 VirtualBox：`管理 → 全局设定 → 常规`，把 **默认虚拟电脑位置** 改为 `F:\VirtualBoxVMs`。
4. 已知现象：本机开启了 WSL2/内核隔离（Hypervisor 在运行），VirtualBox 会以兼容模式运行（VM 窗口右下角显示小乌龟图标），性能略降，属正常，无需处理。

### 2. 下载 Win11 官方 ISO（约 6.5GB）

1. 打开 [微软 Win11 下载页](https://www.microsoft.com/zh-cn/software-download/windows11)。
2. 选 **下载 Windows 11 磁盘映像 (ISO) 适用于 x64 设备** → 版本选多版本 ISO、语言选简体中文 → 下载，保存到 `F:\`。

### 3. 创建虚拟机并装系统（约 40 分钟）

1. VirtualBox → `新建`：类型 Microsoft Windows、版本 Windows 11 (64-bit)；内存 ≥4GB（宿主机内存宽裕就给 8GB）；虚拟磁盘 64GB、动态分配、位置默认（已在全局设定指向 F 盘）。
2. 挂载 ISO（设置 → 存储 → 光驱 → 选择下载的 ISO），启动虚拟机。
3. 安装时选择 **Windows 11 家庭版**——与实际用户群体一致。
4. 不联网、跳过激活：右下角水印不影响任何测试。
5. 首次 OOBE 强制联网登录微软账号时：按 `Shift+F10` 打开命令提示符，输入 `start ms-cxh:localonly` 回车，可跳过联网直接创建本地账号。
6. 进入桌面后安装增强功能（设备菜单 → 安装增强功能），启用 `设置 → 常规 → 高级` 中的双向剪贴板和拖放，方便传文件。

### 4. 打基线快照（关键步骤）

虚拟机选中 → `备份(快照) → 生成`，命名为 **`01-干净系统`**。

> 此后每轮验证完回滚到这个快照，环境永远干净。**任何在虚拟机里做的操作都不要视为持久状态。**

---

## 二、每轮验证流程（约 5 分钟）

1. 启动虚拟机 → 恢复到 `01-干净系统` 快照。
2. 获取安装包，二选一：
   - **推荐**：在虚拟机内用 Edge 打开项目 GitHub Releases 页直接下载——顺便验证真实用户路径（下载入口 → 落地页 → Release 资产）。
   - 备用：从宿主机直接拖放 Setup.exe 进虚拟机（需已装增强功能）。
3. 双击安装，逐项核对下方验收清单。
4. 测试完成后关闭虚拟机 → 恢复 `01-干净系统` 快照，进入下一轮。

## 三、验收清单

安装过程：

- [ ] SmartScreen 弹出「Windows 已保护你的电脑」（当前安装包未签名，属预期；走「更多信息 → 仍要运行」）。签名上线后此项应反转为**不再弹窗**。
- [ ] 全程**未弹出管理员（UAC）授权**——Squirrel 为每用户安装。
- [ ] 安装进度正常完成，无报错。

安装结果：

- [ ] 安装目录存在于 `%LOCALAPPDATA%` 下的产品目录（记录实际目录名作为基线）。
- [ ] 开始菜单快捷方式（及桌面快捷方式，按实际表现记录）已创建。

首次启动：

- [ ] 双击快捷方式，应用窗口正常出现，托盘图标存在。
- [ ] 数据目录 `%LOCALAPPDATA%\DaguanMath\data` 自动创建。
- [ ] 做一道题产生记录 → 完全退出应用 → 重新打开，记录仍在（本地服务读写正常）。

卸载：

- [ ] 「设置 → 应用 → 安装的应用」中能找到并正常卸载。
- [ ] 卸载后检查 `%LOCALAPPDATA%\DaguanMath\data` 是否保留，记录实际行为作为基线（学习记录不应随卸载丢失）。

可选（自动更新冒烟）：

- [ ] 安装上一版 Release → 触发检查更新 → 观察更新到最新版流程（需虚拟机联网）。

## 四、结果记录

每轮验证按现有阶段报告风格记录：日期、被测安装包版本与校验值、虚拟机内 Windows 版本、清单逐项结果、截图。发现的问题按常规流程开修复任务，**不要在虚拟机里尝试修复后当作已解决**——回滚快照后在宿主机改代码重新打包再验。

## 五、边界与注意事项

- 虚拟机内**不要**登录真实微软账号、不要保存个人数据。
- 虚拟机即干净数据目录，天然满足「不写入真实 `%LOCALAPPDATA%\DaguanMath\data`」的仓库约定；如需在虚拟机内做开发调试，才需要显式设置 `DAGUAN_DATA_DIR`。
- 杀软误报（火绒/Defender）**无法**在虚拟机里有效复现或验证——查杀结论是云端信誉机制，与本地环境无关；该问题走 SignPath 签名解决（见 [SignPath申请材料草稿](SignPath申请材料草稿.md)）。
- 本流程只验证 Windows 11 家庭版；如需覆盖 Win10/LTSC 等版本，用同一虚拟机建多个快照分支或另建虚拟机。
