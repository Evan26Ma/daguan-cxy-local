# 大观园数学桌面版 v1.0.3

v1.0.3 修复新版题库目录与章节导航状态，做题页新增题目状态直改与界面字号缩放，并完善学习进度同步。已安装的 v1.0.2 可通过桌面内的“检查更新”或后台更新安装本版本。

## 更新内容

- 修复题库目录与章节导航状态：手机端选中章节后收起目录抽屉，切换章节时内容滚动归零；目录展开、选中与页面内容保持一致。
- 做题页可直接切换题目的收藏、易错、掌握状态；界面文字支持多档字号缩放，选项与按钮同步缩放。
- 完善新版界面的学习进度同步：学习位置按与旧版共享的协议写入，切换版本后能恢复到正在学习的题目。
- 本版随包内置 6,473 道题。当前有 40 张官网图片无法匿名获取，图片接口需要维护者凭据；这不影响题目、答案及解析更新。

桌面更新会在后台下载，用户确认“重启并安装更新”后才安装；更新不会自动中断正在使用的窗口。未签名，Windows SmartScreen 可能显示未知发布者提示。
