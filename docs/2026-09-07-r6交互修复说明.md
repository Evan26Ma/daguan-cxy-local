# 大观园本地题库 r6 交互修复说明

> 计划版本：`2026.09.07-r6`
> 文档日期：2026-09-07
> 当前状态：代码实现完成；自动测试与本地浏览器冒烟验收已通过，完整跨尺寸矩阵仍需在发布前回归。

## 1. 修复范围

本轮只处理以下四项问题，不改变题库内容、学习状态格式、官网同步协议和 AI 服务档案格式：

1. 点击“工具区”后缺少明确的页面切换反馈；
2. 深层章节选择后无法直观返回上一级或切换同级目录；
3. 官网同步入口存在，但首次配置和日常同步步骤不够明确；
4. AI 解答入口常驻页面右侧，干扰题目阅读。

## 2. 工具区切换

### 当前问题

- 工具区内容实际上已经渲染，但顶部仍高亮“学习区”；
- 主内容滚动位置被保留时，新页面标题可能不在视口内；
- 用户缺少“已经进入工具区”的清晰反馈，因此容易误判为点击无效。

### 修改规则

- 点击“工具区”后，顶部“工具区”立即进入选中态，“学习区”取消选中态；
- 工具区标题上方的区域标识显示为“工具区”，不再显示“学习区”；
- 主内容滚动到顶部，并把无障碍焦点移动到“工具区”一级标题；
- 工具区提供四个明确入口：
  - 使用教程；
  - 官网同步教程；
  - 打开同步中心；
  - 界面设置。
- 点击“学习区”后恢复首页、选中态和主内容顶部位置。

## 3. 章节目录返回与同级切换

### 当前问题

- 桌面端最多显示三列，深层目录会把较早的父级列滚出视口；
- 手机端只显示最后一列，缺少显式返回按钮；
- 目录点击事件错误复用了循环结束后的层级变量，深层目录下可能截取错误路径；
- 文本路径只能查看，不能点击跳回任意层级。

### 修改规则

- 章节弹层固定显示“上一级”按钮：
  - 当前位于学科根层时禁用；
  - 点击后删除路径最后一级，并显示该级的同级目录；
  - 触控区域不小于 44px。
- 当前路径改为可点击面包屑：
  - `学科 / 高等数学 / 极限 / 函数 / …`；
  - 点击任意父级后跳回该层，并保留可切换的同级列表；
  - 当前层使用 `aria-current="page"` 标记。
- 每一列保存独立的层级快照，点击同级节点时只替换当前级及其后代路径。
- 父级节点仍然只展开下一层，只有最末级小节会加载题目。
- 选中无题小节时不清空当前题目，弹层保留并解释当前范围无题。
- 键盘行为：
  - `↑/↓`：同一列移动；
  - `Home/End`：移动到该列首项/末项；
  - `→` 或 `Enter`：展开父级；
  - `←`：返回上一级；
  - `Esc`：关闭弹层并把焦点还给章节选择器。

## 4. 官网同步教程

页面新增独立“官网同步教程”，首页、工具区和同步中心都可以打开。

### 4.1 首次配置

1. Windows 双击 `启动本地题库.cmd`，保持本地中控台运行；
2. 在首页“数据同步中心”点击“设置同步”；
3. 登录方式二选一：
   - 优先填写大观园登录码；
   - 没有登录码时填写官网账号和密码；
4. 点击“保存并登录”；
5. 点击“测试读取”，确认能够只读获取官网掌握状态和收藏；
6. 点击“备份并完成首次修复”；
7. 系统先备份浏览器状态、本地状态文件和官网快照，再迁移官网状态。

### 4.2 日常同步

1. 点击“检查官网差异”；
2. 核对官网→本地、本地→官网、冲突、未知题号和题库更新数量；
3. 选择冲突策略：默认按更新时间较新者，时间缺失时官网优先；
4. 确认后点击“应用对账计划”；
5. 系统再次备份，先写本地，再写官网，最后重新读取官网校验；
6. 单项失败时保留错误和待同步标记，不把整批显示为成功。

### 4.3 数据边界

- 双向同步：掌握状态、收藏、最近学习位置；
- 只从官网读取：历史活动日历、官网活动快照；
- 永不上传：易错标记、题目批注、AI Key、AI 服务档案、聊天历史；
- 登录 Token 只保存在本机 `data/cxyonly-integration.json`；
- Token 不返回网页、不进入进度导出、不写入日志、不提交到 Git 仓库；
- 启动应用只检查登录状态，不会自动拉取或改写官网进度。

## 5. AI 入口调整

### 修改规则

- 删除页面右侧常驻的“AI 解答”悬浮标签；
- AI 只能针对一张明确的题目卡片打开：
  - 列表模式：点击对应题卡操作栏中的“AI 解答”；
  - 单题模式：点击当前题卡操作栏中的“AI 解答”；
  - 焦点模式：快捷键 `A` 继续作为当前题目卡片的快捷操作，但不显示全局悬浮入口；
- 首页、工具区、搜索空状态和未选择题目时不显示 AI 入口；
- AI 抽屉关闭后不保留任何常驻按钮，只能再次从题卡进入。

## 6. 兼容与安全

- 不修改 `LocalStateV3` 数据结构；
- 不修改官网同步接口和增量 revision 机制；
- 不修改 AI Key 的本地脱敏存储方式；
- 不把 `data/`、AI 配置、Token、Cookie、账号信息或同步备份加入 Git；
- 保留四套主题、列表/单题模式、焦点模式和现有快捷键；
- 提升页面脚本版本、构建版本和 Service Worker 缓存版本，避免旧页面继续运行。

## 7. 验收标准

### 工具区

- 点击“工具区”后，选中态、标题和内容同时变化；
- 页面自动回到内容顶部；
- 点击“学习区”能正确返回首页。

### 章节导航

- 深层同级切换不会拼接错误路径；
- 父级不加载题目，叶子小节才加载；
- `Esc`、方向键、Home/End、Enter 和焦点恢复正常。

### 同步教程

- 首页、工具区和同步中心均有“同步教程”入口；
- 用户无需阅读仓库文档即可完成首次配置和日常对账；

- 关闭抽屉后不留下悬浮入口。
