# 大观园数学桌面版 v1.0.9

新版首页新增学习战报，可查看最近 1、3、7、30、365 个学习日的学习题数、新题、一遍过、新增收藏和攻克错题。展开详情可查看每日趋势、学习热力图、新题与复习比例、章节表现及累计成就。学习日从本机时间 04:00 开始。

新旧学习界面统一记录动作，支持离线补写、重复请求去重及备份恢复。已有学习记录作为旧题基线，不回填历史战报。看过答案再隐藏、答错后改答案都不会获得一遍过；已攻克题再次答对也不会重复新增攻克。

修复 Windows 桌面快捷方式和任务栏图标缺失，安装器与应用均使用项目图标。
