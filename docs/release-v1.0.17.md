# 大观园数学桌面版 v1.0.17

本版修复 v1.0.16 新增「线代严选题」后的目录导航问题，继续完成 [issue #7](https://github.com/Evan26Ma/daguan-cxy-local/issues/7) 的反馈。

## 修复行为

- 严选、真题范围下，目录只显示当前范围真实有题的下级节点；`线性方程组` 这类 0 题分类不再占位。
- 题单已完整覆盖原章节时，只保留「线代严选题」一个入口。严选范围下线性代数下级不再同时出现原章节和题单两条路径。
- 从当前范围没有题目的分类切换范围时，自动回退到最近可见上级；不会停留在空目录或显示无题的空壳页。
- 章节选择器（目录弹窗）同步应用相同过滤和回退规则。
- 完整范围保持原有目录：原章节、`线性方程组` 与「线代严选题」都保留。
- 同步生成的题单节点新增 `collection_id` 标记，前端据此识别题单，不依赖名称或写死题单 ID。

## 验证

- 新增单元回归：题单去重、0 题分类隐藏、完整范围保留原目录、隐藏节点回退到科目根；另覆盖 v1.0.16 自动更新的旧题库版本（没有 `collection_id` 时按 `manifest.collections` 识别题单）。
- 新增真实浏览器用例：完整范围下线性代数下级显示原章节 + 「线代严选题」；切到严选后只剩「线代严选题」，`线性方程组` 不再出现；从 `线性方程组` 切到严选时标题回退到「线性代数」；题单七章为 40/75/31/73/64/71/22；页面脚本错误为 0。
- 全量 `npm test`：335 项，334 通过、1 失败、0 取消、0 跳过；唯一失败是主线既有 `#7947` 解析数据契约。新增浏览器用例随后单独复跑通过。
- `npm run verify`：7,599 道唯一题目通过，保留 95 张题图缺失警告。
- 题库仍为 7,599 道唯一题目，未重新同步或改动题目内容。
