# 大观园新版 UI 设计标准

本文件是用户确认的设计方案的落地标准。实施者为 ZCode / GLM-5.3-Flash；验收者为当前 Codex 任务。阶段授权见 UI-REDESIGN-CONTROL.md。阅读本文件不代表获准连续执行全部阶段。

## 1. 目标和边界

保留“大观园”名称，为新版建立明亮、鲜橙、年轻有活力、精确的数学学习空间。与旧版的区别来自信息结构、阅读排版和原创数学几何视觉，不是简单换色。启动进入简洁的继续学习首页；题目是核心，AI 按需打开。

旧版完整保留。沿用原生 HTML/CSS/JavaScript，不迁移 React 或重写后端。当前仅 UI；桌面封装、Cloudflare、关机后访问均不实施。不推送、不部署、不替换 Windows 发布包，不改用户凭据、不向真实官网写入同步数据。

当前视觉问题：标题过大与操作文字过小并存；中文字体与正文风格不统一；盒子层层嵌套；橙色抢占所有层级；工具打断题目阅读；首页均等卡片缺乏主次；快捷键及版本控件持续抢占练习空间；样式补丁互相覆盖。对应修复必须在真实长题、公式、图片和 AI 展开状态下成立。

## 2. 设计系统

### 色彩

|用途|值|
|---|---|
|品牌橙|#FF6A1A|
|悬停/按下|#F45D0B / #E95305|
|浅橙选择底|#FFF0E6|
|白底橙文字|#B83D00|
|应用背景|#F5F6F8|
|阅读面|#FFFFFF|
|导航底|#F0F2F4|
|正文/次要文字|#202124 / #687078|
|分隔线/必要控件边界|#E3E6EA / #8A929B|
|成功/错误/警告|#21734A / #BA3543 / #8A5A10|

鲜橙按钮用深色字；深色主按钮用白字。普通大小白字与鲜橙底对比不足，不能这样组合。错误状态不借用品牌橙。用图标/文字补充状态，不仅依赖颜色。橙色集中在首页主视觉、主要动作、当前选中状态；正文保持黑灰。

### 字体、节奏与形状

统一中文无衬线字体：Segoe UI Variable、Segoe UI、Microsoft YaHei UI、Microsoft YaHei、sans-serif。数学继续使用本地 KaTeX。

|用途|字号/行高|字重|
|---|---|---|
|首页标题|30/40|700|
|页面标题|24/34|600|
|章节标题|20/30|600|
|桌面题干/解析|18/32|400|
|普通 UI|14/22|400|
|导航/按钮|14/20|600|
|元信息|13/20|400|
|非关键辅助|12/18|400|

手机正文默认 17/30。桌面阅读字号可选 16/18/20，手机 16/17/19。中文不用额外字距及两端对齐；公式块上下间距 16，超长公式仅在局部滚动。

间距采用 4/8/12/16/24/32/48。桌面页边 32、笔记本 24、手机 16；控件间 8、字段及段落间 16、区域间 32。按钮圆角 10、面板 16、首页主区 20；胶囊仅用于状态。阴影只用于菜单、浮层和对话框，阅读正文不套多层卡片。

图标本地统一线性风格 20px、描边 1.75–2px。品牌标记使用 32 网格：橙色圆角方块、深色成对括号、三段上升折线；16px 版本删去端点装饰。几何品牌图形限括号、圆弧、上升线，放首页/空状态，不侵入题目。禁止假统计图、装饰性循环动画。

动效：按钮 120ms、菜单 140ms 配合 4px 位移、侧栏 200ms、标签页 160ms、保存状态 120ms。遵守 reduced-motion。

## 3. 页面结构与交互

### 应用框架

顶栏 56px；主导航展开 208px、收起 64px；导航行 44px；底部状态 28px。主内容最大 1120px 居中。外框稳定，内容区域滚动。导航为：学习、题库、复习、笔记、学习记录、工具、设置。复习分类放页面内。网页阶段不绘制假的桌面最小化/关闭按钮。

### 首页

启动进入首页。左侧约 2/3 为鲜橙继续学习区，用深字与深色主按钮；展示真实上次章节、题号与继续入口。右侧复习摘要提供易错、收藏、未掌握入口。下方最多三条最近学习记录和科目入口。无历史时显示选择章节，避免强制欢迎弹窗。同步状态留在底部/工具；不伪造学习时长、连续天数。

### 题库

应用导航之外，题库内部目录宽 256px，右侧为章节/搜索结果。搜索 250ms 防抖，结果显示题目、来源、题型；目录父项展开或展示概览，叶章节进入练习。章节行高度至少 64px，细线分组，避免每项一个阴影卡片。

筛选用右侧面板，手机全屏；底部固定重置/应用，上方已选条件可移除。保留已有来源、年份、题型和三个讲师筛选。空结果提供重置入口。搜索、筛选、返回后的上下文一致。

### 做题（最高优先级）

从上到下：返回/面包屑与题序（例如 8/24）→ 13px 元信息和收藏/批注/AI 操作 → 题干与选项 → 展开后的答案/解析 → 教师视频链接 → 稳定操作栏。阅读区最大 760px，桌面内部留白 40px。避免巨大浅色题号、嵌套灰盒、过多分割线。

选项整行可点击；选择态为浅橙底及勾选标记，正确/错误使用对应语义文字与图标。默认 ABC 不全涂橙。答案/解析采用普通标题和段落；原数据未提供步骤时不捏造编号推导。展开解析仅在内容位于屏幕外时适度滚动。

底部操作栏含上一题、显示解析/收起解析、下一题和掌握状态；易错标记独立，不与掌握状态互斥。为固定栏预留内容底部空间；快捷键提示移到帮助。局部收藏/状态变化不能重绘全部正文、清空选区或跳回顶部。

视频显示讲师、课程/分集、时间；保留帕拉迪宇、李艳芳、没咋了映射、筛选及 Bilibili 分集/时间参数。图片保持比例、可放大；缺图保留稳定占位和重试；公式和表格局部横滚，整个页面不得横向溢出。新版本仍支持单题/列表切换，默认单题；旧版默认列表。

### AI 和批注

AI 默认关闭，点击后右侧宽 400px，可调 360–480px；题目与 AI 独立滚动。输入框始终放 AI 面板底部，不额外停靠在题目左侧。用户消息浅灰气泡，AI 回复连续易读；3 个紧凑快捷提示和紧凑模型选择。保留最新“总体路线 → 逐步推导 → 最终答案 → 方法总结”以及“完整解答”提示。

生成中提供停止；用户向上读历史时不强制滚动，显示新内容提示。配置缺失提供设置入口；失败保留输入和上下文并可重试。未发送内容按题目保存草稿，恢复但不自动发送。

批注编辑/预览支持公式；明确保存中/已保存/失败状态。快速切题和切换版本仍可靠保存；历史功能放次级入口。AI/批注手机全屏，返回恢复题目位置，软键盘弹出后输入区可用。

### 其他页面

复习：易错/收藏/未掌握标签页；计数对应真实队列，已掌握仍可标记易错。

笔记：以题目批注列表与详情为主体；已有全局备忘单列“学习备忘”，不丢失旧数据。

记录：真实日期、热力图和数据；不推算不存在的时间或指标。

工具：组卷、导出、备份、恢复、官网同步、教程都有可达入口。

设置：外观与阅读、AI 服务、快捷键、数据、关于。旧版切换放外观/关于及应用菜单，移除做题正文常驻的新旧切换条，但两版入口都清楚可达。无 Cloudflare 空按钮。

## 4. 兼容、响应式、状态

宽度 >=1280 导航展开、AI 并排；1024–1279 导航收起、AI 并排；768–1023 导航抽屉、AI 覆盖面板；<768 单列、AI/批注全屏。并排时题目可用宽度不得低于 520px，否则转覆盖。手机导航有关闭及遮罩，选择页面后自动关闭，不再叠加重复底栏。触控目标至少 44px；200% 缩放不能截断关键操作。

浅色默认，保留深色/护眼/自定义外观。深色：背景 #17191C，面 #202327，次级面 #282D32，文字 #F2F4F6，辅助 #ADB5BE，线 #3A424B，品牌 #FF6A1A，品牌文字 #FFB184。护眼仅柔和调整阅读面；自定义背景不能降低题目可读性。

加载使用尺寸稳定骨架；空状态给下一步；错误保留用户内容并重试；离线说明可用与受限能力；预览权限边界清楚。保存失败阻止会丢失内容的导航。成功优先局部反馈，不反复全局弹窗。

两版共享原有进度、收藏、易错、批注、选题、快捷键、AI 配置；外观分开，迁移可重复且不覆盖新偏好。新阅读设置属于新版本地外观，不进入官网同步。版本偏好合法值 new/old，缺失/损坏默认新版。公共入口恢复偏好，显式旧版入口可访问，保留 query/hash，无跳转循环。切换前保存位置/批注/草稿、等待必要持久化；失败停留；AI 生成中确认后结束再切换；点击当前版本不刷新。

维持业务 API、题库格式、题目 id、预览权限、DAGUAN_DEFAULT_PAGE 及 Windows 打包修正。新版 CSS 重新组织而非无限叠加覆盖；旧版 CSS/JS 独立。缓存覆盖两版及全部映射；仅删除过期应用缓存，不删学习数据。

## 5. 验收标准

实施者每阶段提交实际修改摘要、测试、真实浏览器截图、复现步骤、未验证项，并停下。验收者独立阅读代码、运行检查、浏览器实操和视觉判断。测试通过不能替代视觉验收，自己声称通过不能授权下一阶段。

尺寸：1440×900、390×844 每阶段；最终增加 1280×800、1024×768、360×800。检查长公式、图片题、列表/单题、解析展开、AI 开关/生成/停止/错误/滚动、批注快速切题及保存失败重试、收藏/掌握/易错跨版本共享、位置和草稿、三个讲师参数、组卷/导出/备份/同步入口、离线缓存、键盘、缩放、减少动效、无页面横溢/遮挡/资源丢失/旧版样式泄漏。

最终截图：桌面首页、题库含筛选、做题收起/展开、AI、复习、设置；手机首页、题库、做题、AI；同一道题的新旧对照。真实 AI 未配置则模拟验证并明确真实调用未测。已有缺图需列出，不能声称全部资源完整。
