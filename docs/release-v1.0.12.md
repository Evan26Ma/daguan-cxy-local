# 大观园数学桌面版 v1.0.12

本版汇总 v1.0.11 之后的题库、讲解视频、AI 阅读与学习记录更新，并修复旧记录迁移丢失已有数据的问题。

## 修复与新增

- 旧浏览器迁移只增量导入学习记录。缺少或为空的批注、学习位置不清空本机内容；同题记录按有效时间比较，保留较新的本机内容；同步种子、待重传队列等本机元数据保持原样。
- 合入 `codex/daguan-desktop-stage0` 的独立 owner 检查、锁恢复验证和并发测试。冲突处保留主线较新的服务交接、恢复闸门与桌面下载入口，未恢复停止维护的浏览器发行入口。
- 随机服务端口选择避开 Node/Chromium 禁止访问的低端口，修复随机分配到 4190 等端口时的启动失败；回归执行实际端口分配函数。
- 题源细化为「体系 → 书目」两级分类；新增 1190 道按需加载的结构化精讲解析，包括思路、步骤、原因、易错点与扫描题文字转写，样式跟随主题与字号。
- 扩充李艳芳、喻老、汤家凤等老师的真题讲解时间轴映射。
- 新增学习手账与成长印章；前端拆分数据、状态同步、AI 与共享安全渲染模块。
- AI 使用考研复习视角，支持简短/详细回答与段落追问。按维护者确认，本次保留 AI 接口现有来源策略。
- 新增 `PROJECT_RULES.md`，规范数据、提交、合并与发布；桌面打包排除本机备份、截图与临时预览。

## 验证记录

候选提交、全量测试、打包程序实测与资产校验结果在发布前补入本节。

## 已知限制

- 题库校验包含 6521 道唯一题目，但有 41 张既有题图缺失。资源补齐需要 `DAGUAN_ASSET_TOKEN`；本次未进行需要该凭据的资源同步。
- 沿用未签名发行方式。正式安装器在干净 Windows 用户配置下的安装与从 v1.0.11 自动升级尚未实测；隔离启动验证不能替代这两项验收。
- 本次发布 GitHub 桌面安装包与更新资产。百度网盘中的文件未替换，网盘下载应按实际文件与对应 Release 校验。

## 下载与更新

Windows x64 资产为 `DaguanMathDesktop-Setup.exe`、`DaguanMathDesktop-1.0.12-full.nupkg`、`RELEASES` 和对应三份 SHA-256 校验文件。已安装桌面版可检查更新，下载完成后确认重启并安装更新。
