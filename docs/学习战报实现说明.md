# 首页学习战报

新版首页在继续学习区下展示战报，范围为最近 1、3、7、30、365 个学习日。学习日按浏览器本机时区 04:00 划分；日期移动采用日历运算，支持跨月、跨年及夏令时。详情包含趋势、热力图、新题与复习比例、收藏来源、章节首答样本和累计成就。所有内容仅展示，不新增统计跳题入口。

## 记录与统计

新增 `study-activity.json`，只由持有既有数据目录实例锁的本地服务写入。文件损坏时报错保留原文件，不自动清空。事件包含稳定 ID、题号、动作时间、章节、会话、动作类型和判题信息；同一 ID 重放不重复计数，记录跨年保留。

- `study`：主动标记学习中／已掌握，或非可靠选项作答。
- `answer`：作答；只有可靠自动单选参与首答正确率、一遍过和错题攻克。
- `reveal`：答案已展示，不增加学习题数。隐藏答案和刷新不清除当前会话的展示标记，重新进入另一轮练习才可独立重做。
- `favorite`：从未收藏变为收藏，来源为手动或答错自动收藏；取消不删除历史。

范围内按题号去重，学习量＝新题＋复习题。一遍过要求首次有效学习就是未看答案的可靠正确作答，第一次答错后改对不计入。错题攻克必须有新事件中的可靠答错记录，随后独立答对；旧数据只有最终状态，不能据此证明过去的可靠判题过程。已有学习痕迹的题作为旧题，首次结果未知。

章节只使用未提前看答案的可靠首次作答样本；少于 5 题不作薄弱判断，至少 5 题且正确率低于 60% 时提示值得多练。新题里程碑为 10/50/100/500/1000，攻克不同错题为 1/10/50/100；另外记录活跃日、连续学习和单日最多题数。

## 接口与兼容

个人接口均使用现有预览访问限制：

| 方法与路径 | 用途 |
|---|---|
| `GET /api/study-activity?days=3&timeZone=Asia%2FHong_Kong` | 范围指标、每日序列、章节样本和成就 |
| `POST /api/study-activity/events` | `{ events: [...] }`，每批最多 1000 项；返回确认的事件 ID |
| `GET /api/study-activity/export` | 导出完整事件和历史基线 |
| `POST /api/study-activity/merge` | 备份按事件 ID 合并，重复恢复不刷计数 |

新旧前端共用独立事件待同步队列，每事件一个本地存储键，避免逐题状态合并抹掉中间动作。离线保留原 ID，刷新、联网、超时后重试；跨窗口可共同补写，服务端去重。首页监听本地动作并定时补读，远程 quick 模式没有 SSE 时也可更新。04:00 定时切换学习日，回到前台时补读。

两版 JSON 备份新增 `study_activity`，含事件与基线。恢复旧备份或官网导入只登记旧题基线，不制造学习活动。新备份恢复原有首学历史；离线恢复暂存在独立队列。备份会包含尚未同步的事件，无法读取服务或有效缓存时停止生成，避免输出不完整备份。

## 验证与交付边界

单元测试覆盖 04:00、跨月跨年、夏令时、365 天、去重、首答、收藏来源、错题攻克、样本量、连续学习、并发写入和备份合并。浏览器测试覆盖两版单题／连续模式、答案显隐、范围、详情、跨窗口、150% 布局及离线刷新重试。桌面打包实测使用临时目录，读取真实题库单选题并核对首页战报。
