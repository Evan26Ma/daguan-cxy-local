# 大观园数学桌面版 v1.0.2 发布候选

状态：本地候选包已构建并校验，**尚未推送或创建公开 Release**。目标远端为 `Evan26Ma/daguan-cxy-local`，`v1.0.2` tag 与 Release 在构建时均未占用。

## 改动

- 启动桌面版时，确认浏览器服务的锁、健康身份和协议后请求优雅退出；等待进程和锁释放，再沿用原端口启动桌面服务。原浏览器标签页可以连接新服务并补写待同步记录。
- 对没有来源标识的旧包，仅在锁与健康 PID、实例 ID 匹配，且 Windows 进程映像为旧浏览器可执行文件时接管。死 PID 旧锁按独占恢复闸门处理。身份不明、健康失败、停止超时和锁变化时不启动第二个写入者。
- 最后一个浏览器包的新旧学习界面均显示迁移页，先尝试保存待同步记录，失败时提供本机备份下载。公开下载页只推荐桌面版；浏览器包作为迁移归档。
