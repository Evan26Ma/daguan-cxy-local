# 大观园数学桌面版 v1.0.5

本版加入新版界面的“历史做题记录”，整理官网仍未分类的 492 道题，并更新内置题库。已安装的 v1.0.4 可通过桌面版“检查更新”获取本版；更新下载完成后，需由用户确认重启安装。

## 更新内容

- 新版左侧导航加入“历史”，可按题号、章节、日期和学习状态筛选，并返回题目；历史记录保存在本机。
- 按题号固定映射官网 492 道未分类题：历年真题、Euclid 2027 八月模考和对应高数章节。官网将来提供正式分类时以官网为准，新增未分类题不自动推断。
- 内置题库更新至 6,521 个唯一题号，当前未分类为 0；保留原题号和已有学习记录关联。
- 调整新旧界面与本地使用引导，加入经密码保护的外网浏览器访问入口。
- 修正桌面打包排除规则，安装包不含仓库根目录的本地学习记录和临时草稿。

题库中仍有 41 张官网题图无法匿名获取；题目、答案和解析可正常使用。Windows 安装包尚未签名，SmartScreen 可能显示“未知发布者”。
