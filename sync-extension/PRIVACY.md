# 隐私说明

## 数据处理范围

大观园数据桥接只处理用户主动选择同步的题目掌握状态和收藏。

扩展不会导出或保存：

- 密码和登录令牌；
- 用户名、用户 ID、微信 OpenID 或其他账号资料；
- 题目正文、答案、解析和题图；
- 文字笔记和手写画布；
- 浏览历史和其他网站数据。

## 浏览器权限

| 权限 | 用途 |
| --- | --- |
| `scripting` | 在官网页面运行扩展自带的数据桥接代码 |
| `tabs` | 查找用户主动打开的官网题库标签页 |
| `host_permissions: https://www.cxyonly.fans/*` | 仅访问官网自身接口 |
| `externally_connectable` | 接受默认本地 Web 来源或用户明确配置的固定来源 |

扩展不申请其他网站的 `host_permissions`，也不申请 Cookies、历史记录、所有网站访问、远程代码或后台存储权限。

## 登录状态

扩展在原站页面中临时读取原站已有的登录令牌，并只把它用于请求 `https://www.cxyonly.fans` 自身的接口。令牌不会：

- 写入扩展存储；
- 写入日志；
- 放入导出 JSON；
- 发送到第三方服务器。

对于原站的写入请求，扩展还会临时读取或刷新原站 CSRF 令牌，并通过原站要求的请求头发送；CSRF 令牌同样不会写入扩展存储、导出 JSON 或发送到第三方服务器。

## 导入与备份

导入移动端 JSON 前，扩展会先读取原站当前标记并下载本地备份。只有用户查看预览并再次确认后，扩展才会向原站写入发生变化的题目状态。

备份与导出文件保存在用户浏览器的下载位置，后续保管和分享由用户自行决定。
