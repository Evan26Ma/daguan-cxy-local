# 大观园插件

大观园插件是一个无需编译的 Chrome Manifest V3 扩展，用于在公益题库网站 [大观园数学题库](https://www.cxyonly.fans/math)、本地 Web 刷题站和“大观园数学题库 Android 版”之间同步掌握状态和收藏。

除原有的 JSON 导入导出功能外，扩展现在允许 `http://localhost` 和 `http://127.0.0.1` 本地页面通过受限消息接口执行“从官网读取”和“同步到官网”。

本项目是非官方辅助工具，与原网站及题库制作者不存在官方隶属或授权背书关系，除非后续另有明确说明。

## 功能

- 将原站的“已掌握、需练习、完全不会、收藏”导出为 Android 客户端可直接导入的 JSON。
- 读取 Android 客户端导出的 JSON，将非空掌握状态和已收藏安全合并到原站。
- 写入原站前自动下载完整标记备份。
- 导入前显示变更预览，导入中显示进度、成功数和失败数。
- 插件生成的原站备份可以再次选择并精确恢复。

第一版不会同步文字笔记、手写画布、选择题答案、错题次数、学习事件或最后阅读位置。

## 安装

本扩展没有构建步骤，源码就是可加载的扩展：

1. 下载本仓库源码并解压。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择包含 `manifest.json` 的本仓库根目录。

更新源码后，在扩展管理页面点击本扩展的“重新加载”即可。

## 使用

### 本地 Web 一键同步

1. 在 `chrome://extensions/` 中加载本目录。
2. 打开并登录官网数学题库。
3. 打开本地 Web 站点，在“官网同步”中填写本扩展 ID。
4. 点击读取或同步按钮。

扩展只接受允许的本地来源，只访问 `www.cxyonly.fans`，不会把登录令牌返回给本地页面。同步到官网前会自动下载完整状态备份。

默认允许 `http://localhost:*` 和 `http://127.0.0.1:*`。如果本地 Web 部署在局域网服务器或固定域名上，需同时在 `manifest.json` 的 `externally_connectable.matches` 和 `background.js` 的来源白名单中加入该精确来源，然后重新加载扩展；不要改成所有网站通配符。

### 从原站导出到 Android

1. 打开并登录 <https://www.cxyonly.fans/math>。
2. 点击浏览器工具栏中的“大观园数据桥接”。
3. 点击“导出到移动端”。
4. 在 Android 客户端中打开数据页面，选择“导入源站同步 JSON”。

导出文件只包含有意义的掌握状态和已收藏，不包含账号资料、登录令牌、文字笔记或题库内容。

插件会按原站要求读取当前 CSRF 令牌；令牌只在当前页面内存中用于原站请求，不会写入插件存储或导出文件。

### 从 Android 导入原站

1. 在 Android 客户端中导出同步 JSON。
2. 打开并登录原站。
3. 点击扩展，选择移动端 JSON。
4. 检查变更预览。
5. 点击“备份并导入”，再次确认后开始写入。

普通移动端 JSON 使用安全合并：

- `mastered`、`needs_practice`、`not_known` 会写入原站；
- `favorite: true` 会写入原站；
- `not_started`、`favorite: false` 和缺失题目不会清空原站；
- 未知题号会被跳过并计数。

插件自己的 `daguan-site-marker-backup` 备份使用精确恢复模式，可还原取消收藏和“未开始”状态。选择这种文件时，界面会显示额外警告。

## 权限与隐私

扩展申请：

- `scripting`：把本仓库自带的数据桥接代码注入官网页面；
- `tabs`：查找用户主动打开的官网题库标签页；
- `https://www.cxyonly.fans/*`：仅允许访问官网自己的接口；
- `externally_connectable`：仅接受默认本地 Web 来源，或用户按上文明确配置的固定部署来源。

扩展不申请 Cookies、浏览历史、所有网站访问权限或远程代码。登录令牌只在官网页面内存中临时用于访问官网自己的 API，不会写入扩展或导出文件。详细说明见 [PRIVACY.md](PRIVACY.md)。
