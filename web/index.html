    第一次打开

    1 分钟开始使用

    这是本地优先版本：题库和刷题进度默认留在当前浏览器，断网也能继续刷。只有点击“官网同步”时，才会通过扩展访问大观园官网。

    1. 1
      先刷题

      点击“从高等数学开始”，在题目卡片上展开答案并标记掌握状态。

    2. 2
      要换设备，再备份

      打开“进度备份”下载 JSON；在另一台设备选择文件即可恢复。

    3. 3
      要和官网互通，再同步

      安装同步扩展、登录官网，然后在“官网同步”中读取或上传状态。

    使用教程

    本地刷题 + 官网同步

    日常只需要两个动作：双击启动脚本打开本地题库，刷完后按需点击“官网同步”。

    1. 1

      一键启动本地题库

      Windows 双击仓库根目录的 启动本地题库.cmd，脚本会启动本地服务并打开浏览器。Linux 可运行 python3 -m http.server 8080 --directory web。

    2. 2

      开始刷题

      点左侧分类进入题目；列表模式适合连续刷，单题模式支持快捷键 ← →、A 和 1-4。每次标记会自动保存到当前浏览器。

    3. 3

      备份或迁移进度

      打开侧栏“进度备份”→“下载备份”。换设备时在同一处选择 JSON 文件，写入前不会覆盖题库内容。

    4. 4

      第一次官网同步

      安装 sync-extension/ 未打包扩展，在官网登录并保持官网题库标签页打开。再打开“官网同步”，从扩展弹窗复制扩展 ID，粘贴一次并保存。

    5. 5

      读取或上传

      点击“从官网读取”会先显示变更预览，再合并到本地；点击“预览并同步到官网”会先读取官网状态并自动备份，确认后才写入。默认不会清空官网已有记录。

    同步安全吗？

    本地页面不会接触登录令牌。扩展只访问大观园官网，并且仅传输题号、掌握状态、收藏和更新时间；写入官网前会自动下载备份。

    导出 PDF

    题目卡片左侧可勾选。生成预览后，用浏览器「打印 → 另存为 PDF」。

    范围

    不限题量。题很多时预览会排一会儿，可以先喝口水。

    进度

    进度记在这台设备的浏览器里，手机电脑都能用，不必登录，也不必连大观园。换设备或清站点数据会丢，导出一份 JSON 即可带走。
