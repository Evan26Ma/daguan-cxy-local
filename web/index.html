    第一次打开

    1 分钟开始使用

    这是本地优先版本：题库和刷题进度由本机中控台保存，断网也能继续刷。只有同步时才会访问大观园 API。

    1. 1
      先刷题

      点击“从高等数学开始”，在题目卡片上展开答案并标记掌握状态。

    2. 2
      要换设备，再备份

      打开“进度备份”下载 JSON；在另一台设备选择文件即可恢复。

    3. 3
      要和官网互通，再同步

      在“设置同步”里输入一次大观园登录码，之后在同步中心手动检查差异并应用。

    使用教程

    本地刷题 + 官网同步

    日常只需要两个动作：双击启动脚本打开本地题库，刷完后按需点击“官网同步”。

    1. 1

      一键启动本地题库

      Windows 双击仓库根目录的 启动本地题库.cmd，脚本会自动准备 Node.js、启动中控台并打开浏览器。Linux 可运行 ./scripts/install-linux.sh。

    2. 2

      开始刷题

      点左侧分类进入题目；列表模式适合连续刷，单题模式支持快捷键 ← →、A 和 1-4。每次标记会自动保存到当前浏览器。

    3. 3

      备份或迁移进度

      打开侧栏“进度备份”→“下载备份”。换设备时在同一处选择 JSON 文件，写入前不会覆盖题库内容。

    4. 4

      第一次官网同步

      点击首页“设置同步”，在配置向导中输入大观园登录码。中控台会在本机保存状态并直接访问官网 API，不需要安装扩展或保持官网标签页打开。

    5. 5

      检查并应用

      点击“检查差异”会先更新题库并读取官网状态；确认后应用统一对账计划，先写本地、再写官网并复读校验，失败项会保留。

    同步安全吗？

    本地页面不会接触登录令牌。Node 中控台只向大观园发送题号、掌握状态、收藏和更新时间；写入官网前会自动保存备份。

    导出 PDF

    题目卡片左侧可勾选。生成预览后，用浏览器「打印 → 另存为 PDF」。

    范围

    不限题量。题很多时预览会排一会儿，可以先喝口水。

    进度

    进度优先保存在本机中控台的 data/ 目录，浏览器只保留缓存。关闭网页或重启电脑不会丢失；导出一份 JSON 还可以带到新设备。
